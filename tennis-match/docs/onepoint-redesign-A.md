# 원포인트 화면 개편 — 시안 A(선반) 구현 명세

> **Claude Code에게**
> 이 문서는 레벨업 탭 › **원포인트** 화면을 새 디자인(시안 A, 「선반」)으로 다시 만드는 작업 지시서입니다.
> 코드를 쓰기 전에 **0장 「먼저 확인할 것」**부터 코드베이스에서 찾아보고, 이 문서와 다른 점이 있으면 코드베이스 쪽 관례를 따르세요.
> 추측으로 새 파일·새 컬렉션·새 토큰을 만들지 말고, 기존 것이 있으면 그걸 씁니다.

## 0. 먼저 확인할 것 (작업 시작 전)

코드베이스에서 아래를 찾아 **짧게 정리한 뒤** 작업을 시작하세요.

1. 레벨업 탭 화면 파일과 **원포인트 / 용품 / 코치** 세그먼트가 어떻게 나뉘어 있는지 (한 화면 안의 상태인지, 별도 컴포넌트인지)
2. 지금 원포인트 화면 컴포넌트 (영역 칩 8개, 큰 썸네일 카드, 운영진 「영상 등록」 버튼)
3. 네비게이션 방식: `expo-router`인지 `@react-navigation`인지, 새 화면(영역 모아보기·재생)을 어디에 등록해야 하는지
4. 디자인 토큰 파일 (색 `ink`, `green`, `green2`, `greenSoft`, `lime`, `bg`, `surface`, `text`, `sub`, `border`)과 간격·모서리 상수
5. 영상 데이터가 저장된 곳 (Firestore 컬렉션 경로, 타입 정의, 구독 훅)
6. **운영진(관리자) 판별** 방법 (role 필드, 커스텀 클레임, 훅 이름)
7. 코치 목록을 가져오는 곳 (코치 세그먼트에서 쓰는 데이터) — 「코치 보기」 링크 조건에 씀
8. 설치된 패키지: `react-native-webview`(있음), `expo-image`, `react-native-youtube-iframe`, `@gorhom/bottom-sheet`, `expo-haptics` 설치 여부
9. 하단 탭바 높이를 얻는 방법 (`useBottomTabBarHeight` 등)
10. 영역 이름 상수(`포핸드 · 백핸드 · 발리 · 서브 · 스매시 · 풋워크 · 전술 · 기타`)가 이미 있는지

## 1. 목표와 범위

### 왜 바꾸나

지금 화면에서 나온 문제 여섯 가지를 푸는 것이 목표입니다.

| 문제 | 시안 A의 해법 |
|---|---|
| 머리가 무겁다 (제목+부제+세그먼트+칩 두 줄) | 제목·부제·칩을 빼고 **세그먼트 → 검색창**만 둔다 |
| 게시판 같다 | 영역마다 **가로로 넘기는 선반**, 썸네일 중심, 크기 리듬(새 영상은 크게, 영역 선반은 작게) |
| 검색이 없다 | 검색창을 **늘 보이게** 둔다. 제목·메모·영역에서 찾는다 |
| 한 번에 한 영역만 보인다 | 내려 보면 **모든 영역 선반**이 한 화면에 이어진다 |
| 유튜브로 나가서 안 돌아온다 | **앱 안에서 재생**하고, 유튜브 열기는 보조 버튼으로 둔다 |
| 한 화면에 1.5개만 보인다 | 모아보기·검색 결과는 **촘촘한 줄 목록**(한 화면 5~6개)으로 |

### 이번에 할 것 (1단계)

- 원포인트 첫 화면: 검색창 + 선반
- 검색 상태: 결과 있음 / 결과 없음
- 영역 모아보기 화면
- 앱 안 재생 화면
- 빈 상태: 일반 회원 / 운영진
- 운영진 영상 등록 시트 + 수정·삭제
- 회원별 「봤어요」·「저장」
- 태블릿(가로 넓은 화면) 두 칸 배치

### 이번에 안 할 것 (2단계로 미룸)

- 「이번 주 원포인트」 큰 카드, 「고민으로 찾기」 한 줄 (고민 태그 필드가 필요함)
- 회원의 「이런 영상 부탁해요」 요청 기능
- 초성 검색

## 2. 디자인 규칙 (브리프 그대로, 바꾸지 말 것)

**색 토큰** — 기존 토큰 파일의 값을 import해서 쓰고, 새로 정의하지 마세요.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `ink` | `#132A22` | 다크 영역, 썸네일 자리 배경, 번호 원 |
| `green` | `#0E6B4F` | 주 액션, 선택된 세그먼트·칩, 링크 글자 |
| `green2` | `#10B981` | 진행 막대, 체크 같은 강조 (글자 색으로는 쓰지 말 것 — 대비 부족) |
| `greenSoft` | `#E8F8F2` | 선택 바탕, 영역 배지 바탕, 메모 상자 |
| `lime` | `#8FD6B8` | 다크 위 포인트, 「추천」 배지 바탕 |
| `bg` | `#F8FAFC` | 화면 배경 |
| `surface` | `#FFFFFF` | 카드, 입력칸, 세그먼트 바탕 |
| `text` | `#0F172A` | 본문 |
| `sub` | `#475569` | 보조 글자 |
| `border` | `#E2E8F0` | 테두리, 구분선, 수준 배지 바탕 |

**크기 규칙**

- 간격 8pt 격자: 4 / 8 / 12 / 16 / 20 / 28. 화면 좌우 여백 **16**
- 카드 모서리 16, 썸네일 12(목록 안에서는 10), 버튼 12, 세그먼트 바깥 14
- **터치 최소 높이 48**, 주 버튼 52, 입력칸 56 — 줄이지 말 것
- 본문 15, 굵기 **500 이상** (얇은 글씨 금지). 카드 제목 16/700, 선반 제목 19/800, 화면 제목 22/800
- 글꼴은 시스템 글꼴
- 스크롤 영역 맨 아래에 `tabBarHeight + 24` 여백

## 3. 화면별 명세

### 3.1 원포인트 첫 화면 (영상 6개 이상일 때)

```
┌──────────────────────────────────────┐
│ ┌──────────────────────────────┐ [+] │ ← 세그먼트 56 (항목 48). [+]는 운영진만 56×56
│ │[원포인트]  용품      코치     │     │
│ └──────────────────────────────┘     │
│ ┌──────────────────────────────────┐ │
│ │ 🔍 영상 검색 (예: 슬라이스, 토스)  │ │ ← 검색창 56, 늘 보임
│ └──────────────────────────────────┘ │
│ 새로 올라온 영상                       │ ← 선반 제목 19/800, 높이 48
│ ┌────────┐ ┌────────┐ ┌───           │
│ │  248   │ │        │ │   → 가로 스크롤 │ ← 카드 폭 248, 썸네일 16:9 (248×140)
│ │   ▶    │ │   ▶    │ │                │   3번째 카드가 반쯤 걸쳐 보이게
│ └────────┘ └────────┘ └───           │
│ 토스가 흔들릴 때…  복식 포치…           │ ← 제목 16/700 두 줄까지
│ 서브 · 1분 30초부터                    │ ← 메타 13/600 sub
│                                       │
│ 포핸드  5개                  전체 ›   │ ← 영역 선반. 「전체 ›」 → 영역 모아보기
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌──          │ ← 카드 폭 184 (184×104)
│ │추천 ▶│ │  ▶  │ │  ▶  │ │             │
│ └─────┘ └─────┘ └─────┘ └──          │
│ 백핸드  3개                  전체 ›   │
│ …                                     │
├──────────────────────────────────────┤
│  홈   일정   대진  [레벨업]  더보기     │ ← 기존 탭바
└──────────────────────────────────────┘
```

**중요한 결정**

- 화면 맨 위의 「레벨업」 제목과 부제는 **뺍니다**. 탭바에 이미 「레벨업」이 보이므로 세그먼트가 화면의 첫 줄이 됩니다. 세그먼트는 세 칸 모두가 함께 쓰는 머리이므로 **용품·코치에서도 똑같이** 보이게 맞추세요.
- 영역 칩 두 줄은 **없앱니다**. 영역 이름은 선반 제목이 대신합니다.
- 「전체」 칩도 없습니다. 첫 화면 자체가 전체 보기입니다.

**선반 규칙**

1. **새로 올라온 영상**: `createdAt` 최신순 6개. 카드 폭 248. 전체 영상이 5개 이하면 숨깁니다(3.2의 적은 클럽 모드).
2. **저장한 영상**: 이 회원이 저장한 영상이 1개 이상이면 「새로 올라온 영상」 바로 아래에 보입니다. 카드 폭 184.
3. **영역 선반**: 영역 상수 순서(포핸드 → 기타)대로 보이고, **영상이 0개인 영역은 선반째 숨깁니다**.
   - 선반 안 순서: `pinned` 먼저, 그다음 `createdAt` 최신순
   - 선반에는 최대 10개까지. 「전체 ›」는 늘 보입니다.
4. 선반 제목 줄: 왼쪽에 `영역 이름(19/800)` + `N개(15/700 sub)`, 오른쪽에 `전체 ›`(15/800 green, 터치 영역 48).
5. 가로 목록은 `FlatList horizontal`, `showsHorizontalScrollIndicator={false}`, 좌우 `contentContainerStyle` 여백 16, 카드 사이 12. 다음 카드가 반쯤 걸쳐 보여야 옆으로 넘길 수 있다는 걸 알 수 있습니다(스냅은 쓰지 않음).

### 3.2 영상이 적은 클럽 (전체 1~5개)

선반이 짧으면 휑해 보이므로 선반을 쓰지 않습니다.

- 세그먼트 → 검색창 → `영상 N개` 라벨 → **촘촘한 줄 목록**(3.4의 `VideoRow`)으로 전부 보여 줍니다.
- 정렬: `pinned` → `createdAt` 최신순

### 3.3 검색 상태

검색창을 누르면 검색 모드로 바뀝니다.

```
┌──────────────────────────────────────┐
│ ┌──────────────────────────┐          │
│ │ 🔍 슬라이스            (x) │  취소    │ ← 세그먼트는 숨김. 테두리 green 2px
│ └──────────────────────────┘          │
│ ‘슬라이스’ 영상 4개                     │ ← 18/800
│ 제목 · 메모에서 찾았어요                 │ ← 14/600 sub
│ (전체 4)(백핸드 1)(서브 1)(발리 1) →     │ ← 결과가 있는 영역만 칩으로, 가로 한 줄
│ ┌──────┐ 한손 백핸드 [슬라이스] 기초     │ ← VideoRow. 찾은 글자는 greenSoft 바탕 + green 글자
│ │  ▶   │ [백핸드][입문] 2분 40초부터    │
│ └──────┘                              │
│ …                                     │
└──────────────────────────────────────┘
```

- 입력하는 동안 150ms 디바운스로 결과를 바로 갱신합니다. 검색 버튼은 따로 없습니다.
- 「취소」를 누르면 입력값을 비우고, 키보드를 닫고, 선반 화면으로 돌아갑니다. 안드로이드 뒤로 가기도 똑같이 동작합니다.
- `(x)` 버튼은 입력값만 지웁니다(터치 48).
- 영역 칩으로 결과를 걸러 볼 수 있습니다. 기본은 「전체」입니다.
- 검색어를 비우면 검색 모드는 유지한 채 「최근 찾은 말」 칩을 보여 줍니다(최대 5개, 기기에 저장 — `AsyncStorage` 등 기존 저장소 사용).

**결과 없음**

```
        (🔍)                          ← 72 원, greenSoft 바탕
  ‘킥서브’ 영상은 아직 없어요             ← 21/800
     비슷한 말로 찾아보세요               ← 16/600 sub
   (서브 3) (토스) (스핀)                ← 제안 칩: 검색어가 영역 이름을 포함하면 그 영역 + 자주 쓰는 말
```

「영상 부탁하기」 버튼은 2단계에서 붙입니다. 1단계에서는 제안 칩까지만 만드세요.

### 3.4 영역 모아보기 화면 (새 화면)

선반의 「전체 ›」를 누르면 열립니다.

```
┌──────────────────────────────────────┐
│ ‹  포핸드  5개                         │ ← 뒤로(48) + 제목 22/800 + 개수 16/700 sub
│ [포핸드 5](백핸드 3)(서브 3)(발리 2) →   │ ← 영상 있는 영역만 가로 칩. 누르면 이 화면에서 영역만 바뀜
│ ┌──────┐ 포핸드 스윙 궤도 교정           │
│ │추천 ▶ │ [중급] 3분부터 핵심             │ ← VideoRow: 썸네일 136×76 + 글자, 줄 높이 최소 96
│ └──────┘                              │
│ ┌──────┐ 라켓 면이 열릴 때 잡는 법        │ ← 본 영상: 썸네일 어둡게 + 「✓ 봤어요」, 제목 sub 색
│ │✓봤어요│ [입문]                         │
│ └──────┘                              │
│ …                                     │
│ ───────────────────────────────────── │
│ 포핸드, 직접 봐 줄 사람이 필요하면  코치 보기 › │ ← CoachLine (코치가 1명 이상일 때만)
└──────────────────────────────────────┘
```

- 칩으로 영역을 바꾸면 화면 제목과 목록만 바뀌고, 새 화면을 쌓지 않습니다(`setParams` 또는 상태).
- 정렬: `pinned` → `createdAt` 최신순
- 수준 필터는 1단계에서 넣지 않습니다(영역당 영상이 10개 이하라서).

### 3.5 앱 안 재생 화면 (새 화면, 탭바 없음)

```
┌──────────────────────────────────────┐
│ ‹  포핸드                             │ ← ink 바탕 64, 흰 글자
│ ┌──────────────────────────────────┐ │
│ │        유튜브 플레이어 16:9          │ │ ← 화면 폭 전체
│ └──────────────────────────────────┘ │
│ [포핸드][중급]                          │
│ 포핸드 스윙 궤도 교정                    │ ← 22/800
│ ┌──────────────────────────────────┐ │
│ │ 운영진 메모                         │ │ ← greenSoft 상자, 라벨 13/800 green
│ │ 3분부터가 핵심이에요.                │ │ ← 16/700
│ │ [▶ 3:00부터 보기]                   │ │ ← 메모에서 시각을 찾았을 때만. 흰 바탕 + green 테두리, 48
│ └──────────────────────────────────┘ │
│ [✓ 봤어요] [🔖 저장] [↗ 유튜브]          │ ← 세 버튼 각 48, 같은 폭
│ 포핸드 다음 영상            4개 더 ›    │
│ ┌──────┐ 탑스핀 거는 손목 각도          │ ← 같은 영역의 다음 영상 1개
│ └──────┘                              │
│ ┌──────────────────────────────────┐ │
│ │ 직접 봐 줄 사람이 필요하면  코치 보기 › │ │ ← CoachLine 카드형 (코치 1명 이상일 때만)
│ │ 우리 클럽 코치 2명                   │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

**플레이어 구현**

- 1순위는 `react-native-youtube-iframe`입니다. `react-native-webview` 위에서 도는 JS 패키지라 새 네이티브 빌드가 필요 없습니다. 설치 전에 0장 8번에서 확인하고, 설치가 곤란하면 2순위로 가세요.
- 2순위는 `WebView`에 iframe HTML을 직접 넣는 방식입니다. `source={{ html, baseUrl: 'https://<앱 도메인>' }}`로 origin을 주고, iOS는 `allowsInlineMediaPlayback`, `mediaPlaybackRequiresUserAction={false}`를 켭니다. origin이 없으면 유튜브가 재생 오류를 내는 경우가 있습니다.
- `playsinline=1`, `rel=0`. 시작 위치는 `startAt`(5장)을 씁니다.
- **「3:00부터 보기」**는 플레이어 ref의 `seekTo(startAt, true)`를 호출합니다.
- **재생 오류 처리**: 삽입 금지 영상(오류 101/150), 삭제된 영상, 네트워크 오류가 나면 플레이어 자리에 이렇게 보여 줍니다. 자동으로 앱 밖으로 내보내지는 **않습니다**.
  ```
  이 영상은 앱 안에서 재생할 수 없어요
  [유튜브에서 보기 ↗]   ← 주 버튼 52
  ```
- 「유튜브」 버튼은 `Linking.openURL(원래 url)`입니다.
- **봤어요**: 버튼으로 켜고 끕니다. 재생이 끝나면(`ended`) 자동으로 켭니다.
- **저장**: 켜고 끕니다. 켜면 첫 화면에 「저장한 영상」 선반이 생깁니다.
- 가로로 돌리면 플레이어만 전체 화면이 됩니다(패키지 기본 동작을 따름).

### 3.6 빈 상태

**일반 회원 (영상 0개)** — 검색창도 숨깁니다(찾을 게 없으므로).

```
          [코트 그림 200×120]           ← greenSoft 바탕 + green 선
      아직 올라온 영상이 없어요           ← 21/800
   운영진이 좋은 레슨 영상을 모으고 있어요.  ← 16/600 sub, 가운데 정렬
       [그동안 용품 둘러보기 ›]           ← 글자 링크 → 세그먼트를 「용품」으로
```

**운영진 (영상 0개)**

```
  [운영진으로 보는 중]                     ← ink 바탕 + lime 글자 알약 (운영진 표시)
      첫 영상을 올려 볼까요?               ← 22/800
  유튜브 주소만 붙여 넣으면
  썸네일과 제목은 알아서 채워져요.           ← 16/600 sub
  [ +  영상 등록하기 ]                     ← 주 버튼 52 → 등록 시트
  회원에게는 ‘아직 영상이 없어요’로 보여요    ← 14/600 sub
```

### 3.7 운영진: 영상 등록 입구와 시트

- **입구**: 세그먼트 오른쪽의 `+` 버튼(56×56, green 바탕, 흰 +, `accessibilityLabel="영상 등록"`). 원포인트 세그먼트에서 운영진에게만 보입니다. 기존 목록 맨 아래 「영상 등록 [+ 추가]」 줄은 **지웁니다**.
- **시트**: 아래에서 올라오는 시트. 높이는 화면의 90%, 윗부분은 둥글게(24), 손잡이(40×5)를 둡니다. `@gorhom/bottom-sheet`가 있으면 그걸 쓰고, 없으면 기존 모달 관례를 따르세요.

```
영상 등록                                   (x)
유튜브 주소
┌──────────────────────────────────────┐
│ https://youtu.be/7xK2…            ✓  │ ← 56. 붙여 넣는 즉시 확인
└──────────────────────────────────────┘
┌────────┐ 불러왔어요 · 제목은 고칠 수 있어요   ← 13/800 green
│ 썸네일  │ [포핸드 스윙 궤도 교정        ]   ← 제목 입력칸 48, oEmbed 제목을 미리 채움
└────────┘
영역
[포핸드][백핸드][발리][서브]                  ← 4열 격자, 각 48, 하나만 고름 (필수)
[스매시][풋워크][전술][기타]
┌──────────────────────────────────────┐
│ 추천으로 맨 앞에 두기             (●━) │ ← pinned 스위치
└──────────────────────────────────────┘
- - - - 여기부터는 선택 — 안 해도 돼요 - - - -
수준      [입문] [중급] [상급]              ← 다시 누르면 선택 해제
메모      [3분부터 핵심               ]      ← 56
─────────────────────────────────────────
[              등록하기               ]      ← 주 버튼 52, 시트 아래 고정
```

- 주소를 붙여 넣으면 `parseYouTubeId`로 확인하고, **oEmbed**로 제목을 가져옵니다.
  `GET https://www.youtube.com/oembed?url=<encodeURIComponent(url)>&format=json` → `title`. API 키는 필요 없습니다.
- oEmbed가 401/404를 돌려주면 「앱 안에서 재생이 안 되는 영상일 수 있어요. 그래도 등록하면 유튜브로 열려요.」라는 경고를 보여 주되, 등록은 막지 않습니다.
- 주소 형식이 틀리면 입력칸 아래에 「유튜브 주소가 아닌 것 같아요」를 보여 주고 「등록하기」를 끕니다.
- **이미 등록된 영상**(같은 videoId)이면 「이미 올라온 영상이에요 · 포핸드」를 보여 주고 등록을 막습니다.
- 등록하기가 켜지는 조건: 올바른 주소 + 제목 1자 이상 + 영역 선택
- 등록이 끝나면 시트를 닫고, 토스트 「등록했어요」를 띄우고, 해당 영역 선반을 보이게 스크롤합니다.
- **수정·삭제**: 운영진이 카드나 줄을 **길게 누르면** 액션 시트를 엽니다 — 「수정」(같은 시트를 채워서 열기) / 「추천으로 두기·해제」 / 「삭제」(확인 대화상자 「이 영상을 지울까요? 회원 화면에서도 사라져요」). 일반 회원은 길게 눌러도 아무 일도 없습니다.

### 3.8 코치로 이어지는 자리 — `CoachLine`

광고처럼 보이지 않는 것이 핵심입니다.

- **놓는 곳은 두 군데뿐**: 재생 화면 맨 아래, 영역 모아보기 목록 맨 끝. 첫 화면과 검색 결과에는 **두지 않습니다**.
- **보이는 조건**: 클럽에 등록된 코치가 1명 이상일 때만
- **모양**: 초록으로 채운 버튼은 쓰지 않습니다. 보조 글자(15/600 sub) + 글자 링크 `코치 보기 ›`(16/800 green). 재생 화면에서만 흰 카드(테두리 border)로 감쌉니다.
- **동작**: 레벨업 탭의 세그먼트를 「코치」로 바꿉니다(새 화면을 쌓지 않고 레벨업 탭으로 돌아가서 전환).

### 3.9 태블릿 (창 폭 900 이상)

`useWindowDimensions().width >= 900`이면 두 칸 배치로 바꿉니다.

- 폭 900 미만(폰 가로 포함)에서는 폰 배치를 그대로 씁니다.

## 5. 데이터

### 5.1 영상 문서

기존 필드는 그대로 두고, **새 필드는 모두 선택 입력**입니다. 새 필드가 없는 예전 영상도 똑같이 보여야 합니다.

```ts
type OnePointVideo = {
  id: string;
  title: string;
  category: Category;          // '포핸드' | '백핸드' | … | '기타'
  url: string;
  note?: string;
  createdAt: Timestamp;
  // ↓ 새로 (선택)
  videoId?: string;            // 등록할 때 parseYouTubeId(url)로 저장. 없으면 읽을 때 계산
  level?: 'beginner' | 'intermediate' | 'advanced';
  pinned?: boolean;
  updatedAt?: Timestamp;
  createdBy?: string;          // uid
};
```

화면에 쓰는 수준 이름: `beginner → 입문`, `intermediate → 중급`, `advanced → 상급`.

### 5.2 회원별 상태 (새로)

```
clubs/{clubId}/members/{uid}/videoStates/{videoDocId}
  { watched: boolean, saved: boolean, updatedAt: Timestamp }
```

### 5.3 유틸 (테스트 포함)

React Native의 `URL` 구현은 `searchParams` 등이 빠져 있을 수 있으니, 정규식으로 처리합니다.

```ts
const YT_ID =
  /(?:youtu\.be\/|youtube(?:-nocookie)?\.com\/(?:watch\?(?:.*&)?v=|embed\/|shorts\/|live\/|v\/))([A-Za-z0-9_-]{11})/;

export const parseYouTubeId = (url: string): string | null =>
  url.trim().match(YT_ID)?.[1] ?? null;

export const thumbUrl = (id: string) => `https://i.ytimg.com/vi/${id}/hqdefault.jpg`;

/** 메모나 주소에서 시작 시각(초)을 찾는다. "3분부터", "1분 30초부터", "3:00", "?t=90", "t=1m30s" */
export function parseStartAt(note?: string, url?: string): number | null {
  if (url) {
    const t = url.match(/[?&](?:t|start)=(?:(\d+)m)?(\d+)s?\b/);
    if (t) return (t[1] ? +t[1] * 60 : 0) + +t[2];
  }
  if (!note) return null;
  const mmss = note.match(/(\d{1,2}):([0-5]\d)/);
  if (mmss) return +mmss[1] * 60 + +mmss[2];
  const ko = note.match(/(\d{1,2})\s*분(?:\s*(\d{1,2})\s*초)?\s*(?:부터|~|에서)/);
  if (ko) return +ko[1] * 60 + (ko[2] ? +ko[2] : 0);
  const sec = note.match(/(\d{1,3})\s*초\s*(?:부터|~)/);
  if (sec) return +sec[1];
  return null;
}

export const formatStart = (s: number) =>
  `${Math.floor(s / 60)}:${String(s % 60).padStart(2, '0')}부터 보기`;
```

테스트 케이스:

| 입력 | 결과 |
|---|---|
| `https://youtu.be/dQw4w9WgXcQ` | `dQw4w9WgXcQ` |
| `https://www.youtube.com/watch?v=dQw4w9WgXcQ&t=42s` | ID `dQw4w9WgXcQ`, 시작 42 |
| `https://m.youtube.com/shorts/dQw4w9WgXcQ` | `dQw4w9WgXcQ` |
| `https://example.com/abc` | `null` |
| 메모 `3분부터 핵심` | 180 |
| 메모 `1분 30초부터` | 90 |
| 메모 `2:05 참고` | 125 |
| 메모 `팔꿈치를 보세요` | `null` |

### 5.4 검색

```ts
const norm = (s = '') => s.toLowerCase().replace(/\s+/g, '');   // "스플릿 스텝" = "스플릿스텝"

export function searchVideos(videos: OnePointVideo[], q: string) {
  const k = norm(q);
  if (!k) return [];
  return videos
    .map(v => {
      const score =
        (norm(v.title).includes(k) ? 3 : 0) +
        (norm(v.note).includes(k) ? 2 : 0) +
        (norm(v.category).includes(k) ? 1 : 0);
      return { v, score };
    })
    .filter(x => x.score > 0)
    .sort((a, b) =>
      b.score - a.score ||
      Number(!!b.v.pinned) - Number(!!a.v.pinned) ||
      b.v.createdAt.toMillis() - a.v.createdAt.toMillis())
    .map(x => x.v);
}
```

- 강조 표시는 원문에서 대소문자 무시로 그대로 찾아질 때만 합니다. 띄어쓰기가 달라 원문에서 안 찾아지면 강조 없이 보여 줍니다.
- 결과 없음 화면의 제안 칩: 검색어에 영역 이름이 들어 있으면 그 영역 칩을 먼저 두고, 그다음 「최근 찾은 말」을 최대 3개까지 둡니다.

### 5.5 선반 만들기

```ts
export const CATEGORIES = ['포핸드','백핸드','발리','서브','스매시','풋워크','전술','기타'] as const;

const byPinnedThenNew = (a: OnePointVideo, b: OnePointVideo) =>
  Number(!!b.pinned) - Number(!!a.pinned) || b.createdAt.toMillis() - a.createdAt.toMillis();

export function buildShelves(videos: OnePointVideo[], savedIds: Set<string>) {
  if (videos.length === 0) return { mode: 'empty' as const };
  if (videos.length <= 5) return { mode: 'compact' as const, list: [...videos].sort(byPinnedThenNew) };

  const newest = [...videos].sort((a, b) => b.createdAt.toMillis() - a.createdAt.toMillis()).slice(0, 6);
  const saved = videos.filter(v => savedIds.has(v.id)).sort(byPinnedThenNew);
  const byCategory = CATEGORIES
    .map(c => ({ category: c, items: videos.filter(v => v.category === c).sort(byPinnedThenNew) }))
    .filter(s => s.items.length > 0);
  return { mode: 'shelves' as const, newest, saved, byCategory };
}
```

「다음 영상」(재생 화면): 같은 영역을 `byPinnedThenNew` 순서로 놓고 현재 영상 바로 다음 것을 고릅니다. 없으면 같은 영역의 첫 영상을 고르되, 현재 영상이면 숨깁니다.

| 첫 화면 카드 / 줄 | 누름 | 재생 화면 `{ videoDocId }` |

| `CoachLine` 「코치 보기 ›」 | 누름 | 레벨업 탭으로 돌아가 세그먼트 「코치」 |
| 운영진 `+` / 「영상 등록하기」 | 누름 | 등록 시트 |
| 운영진 카드·줄 | 길게 누름 | 액션 시트 (수정 / 추천 / 삭제) |

뒤로 가기(안드로이드 하드웨어 포함)는 검색 모드 해제 → 이전 화면 순서로 동작합니다.

## 7. 접근성·야외 가독성

- 모든 누르는 요소는 높이 48 이상입니다. 작은 아이콘 버튼은 `hitSlop`이 아니라 **실제 크기**로 48을 맞춥니다.
- `accessibilityRole` / `accessibilityLabel`
  - 카드·줄: `"{제목}, {영역}, {수준}, 봤어요"`처럼 읽히게
  - `+`: `"영상 등록"` / `(x)`: `"검색어 지우기"` / 뒤로: `"뒤로"`
  - 봤어요·저장: `accessibilityState={{ selected }}`
- 글자 키움 설정: 카드 제목과 메타에 `maxFontSizeMultiplier={1.3}`. 선반·목록 높이는 고정하지 말고 글자에 따라 늘어나게 합니다.
- `green2`와 `lime`은 흰 바탕 위 **글자 색으로 쓰지 않습니다**(대비 부족).
- 탭하면 가벼운 햅틱(`expo-haptics`가 있으면 봤어요·저장·등록에만)

## 9. 작업 순서 (커밋 단위)

1. **유틸 + 테스트** — `parseYouTubeId`, `thumbUrl`, `parseStartAt`, `formatStart`, `searchVideos`, `buildShelves`
2. **표시 컴포넌트** — `VideoThumb`, `VideoCard`, `VideoRow`, `VideoShelf`, `SearchField`, `CategoryChips`, `CoachLine`, `EmptyState`
3. **첫 화면** — 머리 정리(제목·부제·칩 제거, 세 세그먼트 공통), 선반 모드, 적은 클럽 모드, 빈 상태 두 가지, 탭바 여백
4. **검색 모드** — 결과·필터 칩·강조·결과 없음·최근 찾은 말
5. **영역 모아보기 화면** + 화면 등록
6. **재생 화면** — 플레이어, 시작 위치, 오류 처리, 다음 영상, CoachLine
7. **회원별 상태** — 봤어요·저장 저장소, 보안 규칙, 「저장한 영상」 선반, 썸네일의 봤어요 표시
8. **운영진** — `+` 입구, 등록 시트(oEmbed·중복·검증), 길게 눌러 수정·추천·삭제, 보안 규칙
9. **태블릿** 두 칸 배치
10. **정리** — 옛 원포인트 컴포넌트와 쓰지 않는 스타일 삭제, 타입 검사·린트 통과

각 단계가 끝날 때마다 타입 검사와 테스트를 돌리고, 화면 단계(3~9)는 안드로이드 에뮬레이터에서 확인해 주세요.

## 10. 완료 기준 (체크리스트)

- [ ] 영상 20개인 클럽: 첫 화면에서 스크롤 없이 세그먼트 + 검색창 + 「새로 올라온 영상」 선반 + 다음 선반 제목까지 보인다
- [ ] 영상이 없는 영역은 선반이 없다
- [ ] 선반 오른쪽 끝에 다음 카드가 반쯤 걸쳐 보인다
- [ ] 「슬라이스」 검색 시 제목·메모에 들어간 영상이 모두 나오고, 「스플릿스텝」으로 「스플릿 스텝」이 찾아진다
- [ ] 결과 없음 화면이 나오고, 「취소」를 누르면 선반으로 돌아간다
- [ ] 영상 1~5개 클럽은 줄 목록으로 보인다
- [ ] 영상 0개: 회원에게는 안내만, 운영진에게는 「영상 등록하기」가 보인다
- [ ] 카드를 누르면 앱 안에서 재생되고, 메모에 「3분부터」가 있으면 「3:00부터 보기」가 동작한다
- [ ] 삽입 금지 영상은 오류 안내 + 「유튜브에서 보기」로 처리된다
- [ ] 봤어요·저장이 앱을 다시 켜도 유지되고, 다른 회원에게는 보이지 않는다
- [ ] 운영진만 `+`와 길게 누르기 메뉴를 볼 수 있고, 규칙상 일반 회원은 영상 문서를 쓸 수 없다
- [ ] 주소를 붙여 넣으면 제목이 채워지고, 같은 영상은 두 번 등록되지 않는다
- [ ] 코치가 0명인 클럽에서는 CoachLine이 어디에도 없다
- [ ] 모든 누르는 요소가 48 이상이고, 굵기 500 미만 글자가 없다
- [ ] 마지막 항목이 탭바에 가리지 않는다
- [ ] 폭 900 이상에서 왼쪽 영역 목록 + 오른쪽 격자로 보인다
- [ ] 용품·코치 세그먼트의 머리도 같은 모양으로 바뀌었다
