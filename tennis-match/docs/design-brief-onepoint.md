# 원포인트 영상 화면 — UI 디자인 요청서

> 이 문서를 그대로 Claude Design에 붙여 넣고 시안을 요청하세요.
> 맨 아래 **「요청 사항」**과 **「답해 줬으면 하는 질문」**이 핵심입니다.

---

## 1. 앱과 이 화면

**테니스매치** — 동호회 테니스 클럽 운영 앱 (React Native · Expo, 안드로이드·아이폰 휴대폰이 주력, 태블릿에서도 열림).

- 하단 탭 다섯 개: **홈 · 일정 · 대진 · 레벨업 · 더보기**
- **레벨업** 탭 안에 위쪽 칸 나누기(세그먼트)로 **원포인트 / 용품 / 코치** 세 칸
- 이번에 다시 그릴 곳은 **원포인트** — 포핸드·백핸드·서브 같은 영역별 유튜브 레슨 영상 모음

### 이 화면이 하는 일 (왜 있나)

1. 회원이 **부담 없이** 들어와서 자기가 약한 부분 영상을 찾아본다.
2. 보다가 "나 이거 안 되는데" 싶은 순간 → 자연스럽게 **코치(레슨)**로 이어진다.

⚠️ **영업·광고처럼 보이면 안 됩니다.** 「레슨」이라는 단어를 입구에 쓰지 않은 것도 이 때문입니다.
입구는 "공짜로 얻어 가는 것"만 약속해야 사람들이 들어옵니다. 코치는 **맨 뒤**, 영상 끝에 조용히.

### 누가 쓰나

- 주 사용자 **40~60대** 동호인. 글자는 크고 굵게, 누르는 곳은 넉넉하게.
- **코트에서, 야외 햇빛 아래** 여는 일이 많음 → 대비 높게.
- 영상 등록은 **클럽 운영진**(관리자)만. 일반 회원은 보기만.
- 클럽 하나에 영상은 보통 **10~60개** 정도 예상 (영역당 0~10개).

## 2. 지금 화면과 문제

### 지금 구조 (위→아래)

```
┌─────────────────────────────┐
│ 레벨업                        │ ← 화면 머리
│ 포핸드·백핸드·서브 — 영역별…     │
├─────────────────────────────┤
│ [원포인트] [ 용품 ] [ 코치 ]   │ ← 세그먼트
├─────────────────────────────┤
│ (포핸드)(백핸드)(발리)(서브)    │ ← 영역 칩 8개가
│ (스매시)(풋워크)(전술)(기타)    │   두 줄로 감김
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │   큰 썸네일 (높이 170)     │ │ ← 영상 카드가
│ │          ▶              │ │   세로로 한 줄씩
│ ├─────────────────────────┤ │
│ │ (포핸드)  제목             │ │
│ │ 메모                      │ │
│ └─────────────────────────┘ │
│  …                          │
│ 영상 등록  [+ 추가]  (운영진)  │
└─────────────────────────────┘
```

- 영역: **포핸드 · 백핸드 · 발리 · 서브 · 스매시 · 풋워크 · 전술 · 기타** (8개)
- 영상을 누르면 **유튜브 앱/브라우저로 나감** (앱 밖으로 나감)
- 「전체」 칩은 이번에 뺐음 → 처음 열면 영상이 있는 첫 영역이 선택됨

### 사용자가 느낀 문제 (앱 주인의 말 그대로)

> "위에 헤더 느낌으로 선택하게 되어 있는데 UI를 개선할 수 없나?
> 너무 **게시판 같아** 보이지도 않게 하는 것도 중요하지만
> 뭔가 **검색도 안 되고** 영상 **찾고 보는 데 좋은 형태는 아닌 것** 같아서."

정리하면:

1. **머리가 무겁다** — 화면 머리 + 세그먼트 + 칩 두 줄. 영상이 화면 절반 아래에서 시작.
2. **게시판 같다** — 똑같은 카드가 세로로 반복될 뿐, "둘러보고 싶은" 느낌이 없음.
3. **검색이 없다** — "슬라이스", "토스" 같은 말로 찾을 수 없음.
4. **한 번에 한 영역만** 보임 — 뭐가 있는지 훑어볼 수 없음.
5. **보는 경험이 끊긴다** — 누르면 앱 밖(유튜브)으로 나가서 돌아오지 않음.
6. 영상 카드가 너무 커서 한 화면에 **1.5개**밖에 안 보임.

## 3. 데이터 (지금 있는 것 / 더할 수 있는 것)

지금 영상 하나가 가진 정보:

| 필드 | 내용 | 예 |
|---|---|---|
| `title` | 제목 | 포핸드 스윙 궤도 교정 |
| `category` | 영역 (8개 중 하나) | 포핸드 |
| `url` | 유튜브 주소 → 썸네일 자동 | https://youtu.be/… |
| `note` | 운영진 메모 (선택) | 3분부터 핵심 |
| `createdAt` | 등록 시각 | |

**디자인에 필요하면 더할 수 있습니다** (운영진이 등록할 때 한 번 더 고르는 정도의 부담이면 OK):

- 수준 (입문 / 중급 / 상급)
- 고민 태그 ("공이 떠요", "더블폴트", "네트에 걸려요" 같은 증상)
- 운영진 추천 고정(핀)
- 영상 길이 (유튜브에서 자동으로 못 가져옴 → 수동 입력 필요, 가능하면 피하고 싶음)
- 회원별 "봤어요" / "저장" 표시

앱에 `react-native-webview`가 이미 들어 있어 **앱 안에서 유튜브를 재생**하는 것도 가능합니다(새 빌드 없이).

## 4. 디자인 규칙 (지켜야 할 것)

- 색 (앱 전체 토큰, 바꾸지 말 것)
  - `ink #132A22` 다크 카드·히어로 · `green #0E6B4F` 주 액션 · `green2 #10B981` 강조
  - `greenSoft #E8F8F2` 선택 바탕 · `lime #8FD6B8` 다크 위 포인트
  - `bg #F8FAFC` 배경 · `surface #FFFFFF` 카드 · `text #0F172A` 본문 · `sub #475569` 보조 · `border #E2E8F0`
- 간격 8pt 격자 (4 / 8 / 12 / 16 / 20 / 28), 카드 모서리 16, 버튼 12
- **터치 최소 높이 48**, 주 버튼 52, 입력칸 56 — 줄이지 말 것
- 본문 15, 굵기 500 이상 (얇은 글씨는 햇빛에 안 보임)
- 글꼴: 시스템 글꼴 (한글)
- 하단 탭바가 화면 아래를 가림 → 마지막 항목 밑 여백 필요
- 위쪽 **[원포인트 / 용품 / 코치] 세그먼트는 유지** (레벨업 탭 구조)
- 운영진용 "영상 등록"은 일반 회원 화면을 어지럽히지 않게 (예: 오른쪽 위 + 버튼 → 아래에서 올라오는 시트)

## 5. 개발 쪽에서 먼저 생각해 본 방향 (참고용 — 더 좋은 안이 있으면 그걸로)

### 안 A. 영상 앱처럼 "선반" 넘기기 ⭐ 추천

```
[원포인트] [용품] [코치]
🔍 영상 검색 (예: 슬라이스, 토스)
─────────────
새로 올라온 영상            ← 가로로 넘기는 줄
[썸네일][썸네일][썸네일] →
포핸드  5 ›                ← 영역마다 한 줄
[썸네일][썸네일][썸네일] →
백핸드  3 ›
[썸네일][썸네일] →
…
```

- 칩 두 줄 대신 **영역별 가로 선반**. 스크롤 한 번에 뭐가 있는지 다 보임.
- 영역 이름 누르면 그 영역만 모아 보는 화면.
- 검색창은 늘 위에. 입력하면 선반 대신 결과 목록.
- 영상이 없는 영역은 선반을 숨김.

### 안 B. "내 고민"에서 시작

```
어디가 고민이세요?
[공이 자꾸 떠요] [백핸드가 불안해요] [더블폴트]
[네트 앞이 무서워요] [발이 안 움직여요] …
```

- 기술 이름이 아니라 **증상**으로 들어옴 → 동호인 말투에 맞음.
- 고민 → 영상 2~3개 → 끝에 "직접 봐 줄 코치 보기" (코치로 가는 가장 자연스러운 다리).
- 고민 태그 필드가 새로 필요.

### 안 C. 결과·영역 목록은 촘촘하게

- 큰 카드(썸네일 170) 대신 **왼쪽 작은 썸네일 + 오른쪽 제목·메모** 한 줄 (유튜브 검색 결과처럼).
- 한 화면 1.5개 → 5~6개.

→ 개발 쪽 생각: **A를 기본으로, 목록은 C**, B는 태그가 쌓이면 A 맨 위에 한 줄로 얹기.

## 6. 요청 사항

1. 원포인트 화면 **시안 2~3개** (휴대폰 세로 390×844 기준). 위 A/B/C를 참고하되 더 좋은 구조가 있으면 제안해 주세요.
2. 각 시안마다 이 상태를 보여 주세요:
   - 처음 열었을 때 (영상 20개쯤 있을 때)
   - 검색어를 입력했을 때 (결과 있음 / 없음)
   - 한 영역만 모아 볼 때
   - 영상이 **하나도 없을 때** (일반 회원 / 운영진 각각)
   - 영상을 눌렀을 때 — 앱 안 재생이면 그 화면, 밖으로 나가면 그 흐름
3. 운영진 "영상 등록" 입구와 등록 시트
4. 코치로 이어지는 자리 (광고처럼 보이지 않게)
5. 태블릿(가로 1024 이상)에서는 어떻게 넓어지는지 한 장

## 7. 답해 줬으면 하는 질문

1. **선반(A) vs 고민(B)** — 40~60대 동호인에게 첫 화면으로 어느 쪽이 더 잘 먹힐까요? 둘을 섞는다면 비율은?
2. 영역 8개를 어떻게 보여 주는 게 좋을까요? (가로 스크롤 칩 한 줄 / 선반 제목 / 아이콘 격자 / 아예 숨기고 검색만)
3. 검색창은 **늘 보이게** vs **돋보기 아이콘 → 펼침** 중 어느 쪽?
4. **앱 안 재생** vs **유튜브로 나가기** — 앱 안에서 재생하면 무엇을 같이 보여 줄까요? (메모, 같은 영역 다음 영상, 코치 연결)
5. 영상이 적은 클럽(5개 이하)에서도 휑해 보이지 않게 하려면?
6. "게시판 같지 않다"는 느낌을 내는 요소 — 썸네일 비율, 제목 위치, 여백, 색 중 무엇이 가장 크게 작용하나요?
7. 영상 길이·"봤어요"·수준 표시 중 **꼭 있어야 하는 것**과 **없어도 되는 것**은?
8. 코치 연결은 어디에, 어떤 말투로? (예: "직접 봐 줄 사람이 필요하면")

## 8. 결과물 형식

- 화면별 이미지 또는 HTML 시안
- 각 시안의 **장단점 3줄씩**
- 추천 시안 하나와 그 이유
- 새로 필요한 데이터 필드 목록 (있다면)
