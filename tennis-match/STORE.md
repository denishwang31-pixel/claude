### 스크린샷 계획 (세로, 순서대로 4~6장)
**심사용 시험 클럽**(「테니스매치 심사용 계정」 워크플로)으로 로그인해서 찍으면 실제 회원 이름이 나오지 않는다.
실제 클럽 화면을 쓸 거면 회원 이름이 보이는 화면은 빼거나 가린다.

| # | 화면 | 보여 줄 것 | 캡션 (스크린샷 위에 얹을 한 줄) |
|---|---|---|---|
| 1 | 홈 | 다음 모임 카드 + 참석 버튼 | 다음 모임, 누르면 바로 참석 |
| 2 | 일정 | 내 코트 모임 목록 + 참석·불참·미응답 명단 | 누가 오는지 한눈에 |
| 3 | 대진 | 날짜 줄 + 대진표 | 대진은 자동으로, 출전은 고르게 |
| 4 | 출석부 | 투표로 채워진 출석부 + 확정 버튼 | 출석은 확정만 누르면 끝 |
| 5 | 대회 찾기 | 접수 중 대회 카드 | 협회·오픈 대회를 한곳에서 |
| 6 | 로그인 | 카카오·네이버·구글 버튼 | 카카오·네이버로 3초 가입 |

캡션을 얹은 스크린샷(스토어용 틀)이 필요하면 캡처 파일을 주면 같은 모양으로 만들어 준다.

**다시 찍으면 좋은 3장 (2026-09-30 1차본 기준)**
- 1 홈: 맨 위 카드가 다른 코트장 모임(참석 체크 안 됨)이었다 → 앱 업데이트 뒤엔 내 코트 모임이 먼저 나온다. 다시 캡처.
- 4 출석부: 투표가 없던 지난 모임이라 전원 「결석」으로 보인다 → 참석 투표가 채워진 모임(예: 이번 주 일요일 모임이 끝난 뒤)으로.
- 5 대회 찾기: 목록이 0건 → 대회 자동 갱신(또는 지금 찾기)이 한 번 돈 뒤 접수 중 대회가 보일 때.

## 3. 앱 콘텐츠 — 데이터 보안 답안표

> 기준: **이 앱의 코드가 실제로 모으는 것** (2026-09-30 확인).

### 공통 질문
| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | **예** (수집함) |
| 전송 중 암호화되나요? | **예** (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** — 앱 안 [더보기] → [내 프로필] → [계정 삭제], 웹 `https://tennis-match-52b31.web.app/delete-account` |
| 제3자와 **공유**하나요? | **아니요** — Firebase(Google)·Expo(알림 중계)는 우리 대신 처리하는 **서비스 제공업체**라 "공유"가 아니다. 카카오·네이버·구글은 로그인 정보를 **받아 오는** 곳이다 |

### 수집하는 데이터 유형 (각각: 수집 ○ · 공유 ✕)
| 분류 | 항목 | 필수/선택 | 목적 | 비고 |
|---|---|---|---|---|
| 개인 정보 | **이름** | 필수 | 앱 기능, 계정 관리 | 이름 또는 별명 |
| 개인 정보 | **이메일 주소** | 필수(이메일 가입) / 선택(소셜) | 계정 관리 | 카카오는 동의한 경우만 |

| 개인 정보 | **전화번호** | 선택 | 앱 기능 | 코치로 등록하는 사람만(지금은 숨긴 메뉴). 코치 메뉴를 열기 전이면 "수집 안 함"도 가능 — 열 때 바꾼다 |

| 금융 정보 | **기타 금융 정보** | 선택 | 앱 기능 | 회비 납부 여부·금액 — 클럽 운영진이 기록. 앱 안 결제 없음 |

| 앱 활동 | **기타 사용자 제작 콘텐츠** | 선택 | 앱 기능 | 게시판 글·댓글 |
