# 테니스매치 사용 설명서

테니스 동호회의 일정·참석·대진·회비를 한곳에서 관리하는 앱입니다.

이 문서는 **지금 앱에 실제로 있는 기능만** 적었습니다. 화면 이름은 앱에
보이는 글자 그대로입니다.

---

## 0. 시작하기 전에 — 나는 어느 쪽인가

| | 무엇을 하나 | 어디부터 읽나 |
|---|---|---|
| **회장·총무** | 클럽을 만들고 회원·일정·회비를 관리 | 1장부터 순서대로 |
| **회원** | 참석 체크하고 대진 확인 | 1장 → 7장 |
| **처음 둘러보는 사람** | 가입 없이 구경 | 1-3 |

---

## 1. 앱 설치와 로그인

### 1-1. 설치

카톡으로 받은 링크나 QR을 누르면 설치가 시작됩니다.

안드로이드에서 **"출처를 알 수 없는 앱"** 경고가 뜨면, 안내를 따라
**설치 허용**을 켜 주세요. 스토어에 아직 올리지 않은 앱이라 그렇습니다.

### 1-2. 로그인 — 세 가지 길

| 방법 | 걸리는 시간 | 비고 |
|---|---|---|
| **구글로 시작하기** | 몇 초 | 가장 빠릅니다 |
| **이메일로 계속하기** | 1분 | 이메일 + 비밀번호(6자 이상) |
| **계정 없이 클럽 둘러보기** | 즉시 | 구경만 — 참석·대진·회비는 못 씁니다 |

이메일로 가입할 때는 **이용약관 동의**에 체크해야 가입 버튼이 켜집니다.

비밀번호를 잊었으면 로그인 화면의 **비밀번호를 잊으셨나요?** 를 누르면
재설정 메일이 갑니다.

### 1-3. 계정 없이 둘러보기로 볼 수 있는 것

- 게시판의 **공개 글** (다른 클럽의 회원 모집·코트 양도 등)
- **게스트 모집** 게시판
- **코트 검색**, **대회 찾기**
- 하단 **레벨업** 탭 — 원포인트 · 용품 · 코치

참석 투표·대진표·회비는 클럽에 들어가야 보입니다.

## 2. 클럽 만들기 (회장)

로그인하면 클럽이 없는 사람에게 클럽 화면이 먼저 뜹니다.
**새 클럽 만들기** 를 고르고 아래를 채웁니다.

| 칸 | 설명 |
|---|---|
| 클럽 이름 | 검색에 이 이름으로 나옵니다 |
| 활동 지역 | 시/도 → 시·군·구 에서 고릅니다 |
| 코트 면수 | 보통 쓰는 면 수 |
| 시작 / 종료 시각 | 정기 운동 시간대 |
| 한 타임 길이 | 기본 40분 (10~120분, 5분 단위) |
| 내 프로필 | 이름·성별·조(선택) |

만들면 바로 홈으로 들어갑니다. 만든 사람이 **회장**이 됩니다.

> 세부 설정은 나중에 **[더보기] → 클럽 운영 → 클럽 설정** 에서 바꿀 수
> 있습니다.

---

## 3. 클럽에 들어가기 (회원)

### 3-1. 초대 링크로 — 가장 쉽습니다

회장이 보낸 링크를 누르면 **로그인만 하면 바로 가입**됩니다. 승인 절차가
없습니다.

### 3-2. 초대코드로

**클럽 찾기** 검색창에 받은 코드를 그대로 넣으면 그 클럽이 나옵니다.

### 3-3. 검색해서 가입 신청

클럽 이름으로 검색 → **가입 신청**. 회장·총무가 승인하면 들어갑니다.
클럽이 가입 비밀번호를 걸어 뒀다면 비밀번호로 즉시 들어갈 수도 있습니다.

승인을 기다리는 동안에는 대기 화면이 뜨고, **승인되는 즉시 자동으로**
클럽 화면으로 넘어갑니다.

---

## 4. 회원 관리 (회장·총무)

### 4-1. 초대하기

**[더보기] → 클럽 운영 → 클럽 초대**

- **초대 링크 복사** — 카톡에 붙여넣기. 누르면 바로 가입됩니다
- **초대 문구 복사** — 클럽 이름과 코드가 들어간 안내문
- 코드만 알려 줘도 됩니다

같은 화면에서 **공개 목록 노출**을 켜면 다른 사람이 클럽 검색으로
찾아 신청할 수 있습니다.

### 4-2. 가입 신청 승인

**[더보기] → 클럽 운영 → 가입 신청** 에서 승인/거절합니다.
신청이 있으면 홈의 [가입 신청] 에 빨간 숫자가 붙습니다.

### 4-3. 오프라인 회원 등록 — 앱을 안 쓰는 분

나이가 있으셔서 앱을 안 깔거나, 아직 초대를 못 한 분도 **명단에는
있어야** 대진과 회비가 맞습니다.

**[더보기] → 클럽 운영 → 회원 목록** → 아래 **회원 추가 (오프라인 등록)**
→ **+ 추가**

| 칸 | 설명 |
|---|---|
| 이름 | 필수 |
| 성별 | 남/여 — 혼복 편성에 씁니다 |
| 클럽 내부 조 | A·B·C… (선택) |
| 테니스 시작일 | 예: `2019-03` (선택) |
| 직책 | 회원·리드·운영진… |
| **소속 코트장** | 여러 곳 선택 가능 |

> ⚠️ **소속 코트장을 꼭 정해 주세요.** 일정과 참석 투표가 이 값으로
> 갈립니다. 코트장이 여러 곳인데 비워 두면 그분에게 엉뚱한 코트 일정이
> 갑니다.

오프라인 회원은 **참석 체크를 운영진이 대신** 해 줍니다. 대진·전적·회비는
앱 회원과 똑같이 잡힙니다.

나중에 그분이 앱에 가입하면 같은 사람이 둘이 됩니다 — 지금은 **합치는
기능이 없습니다.** 가입 전에 오프라인으로 넣어 두셨다면, 가입한 뒤
오프라인 쪽을 지우고 새 계정에 조·소속을 다시 넣어 주세요.

### 4-4. 직책 바꾸기

**회원 목록** 에서 회원을 누르면 직책을 바꿀 수 있습니다.

| 직책 | 할 수 있는 일 |
|---|---|
| **회장** | 전부 + 직책 임명 |
| **총무** | 운영 전반 + 회비·지출 |
| **운영진** | 일정·대진·회원 (회비는 못 봄) |
| **리드** | 내가 맡은 코트장만 |
| **회원** | 조회 + 본인 참석 체크 |

한 사람이 **여러 직책을 같이** 가질 수 있습니다 (운영진이면서 화요일
코트 리드 등).

> 회장·총무 자리는 **회장만** 임명할 수 있습니다. 나머지는 운영진도
> 정할 수 있습니다.

## 5. 코트장 등록 (회장·총무)

클럽이 정기적으로 쓰는 코트를 등록합니다. 여러 곳이면 각각 등록하세요.

**[더보기] → 클럽 운영 → 코트장 관리** → **+ 추가**

| 칸 | 설명 |
|---|---|
| 코트장 이름 | 예: 과천시민회관 테니스장 |
| 면수 | 1~20 |
| 시작 / 종료 | 이 코트장을 쓰는 시간대 |
| **코트 이름** | 면마다 하나씩 — 아래 참고 |
| 한 타임 길이 | 기본 40분 |
| 리드 담당자 | 이 코트장 운영을 맡을 회원 |

### 코트 이름을 꼭 채우세요

기본은 `1` `2` `3` 입니다. 그런데 현장에서는 **A·B·C** 로 부르거나,
그 코트장 전체 번호 중 우리가 빌린 **9·10·11** 만 쓰기도 합니다.

여기 적어 두면 **대진표에 그 이름 그대로** 나옵니다. 표와 현장이 다른
말을 하면 사람들이 표를 안 보게 됩니다.

- 같은 이름을 두 번 쓸 수 없습니다 (표에서 구별이 안 되니까요)
- 8자까지
- 비워 두면 1·2·3 그대로입니다

> 면수를 줄이면 뒤쪽 이름도 같이 지워집니다.

## 6. 일정 등록 (회장·총무·운영진)

**[일정] 탭** → 오른쪽 위 **＋ 새 모임**

| 칸 | 설명 |
|---|---|
| 코트장 | 고르면 시간·면수·타임이 자동으로 채워집니다 |
| 날짜 | 오늘 이후 |
| **시작 / 종료 시간** | 종료를 바꾸면 **타임 수가 자동 계산**됩니다 |
| 코트 표면 | 하드·클레이 등 (선택) |
| 경기 종료 점수 | 한 경기를 몇 게임까지 |
| 랭킹에 반영 | 끄면 이 모임 결과가 랭킹·전적에 안 들어갑니다 |
| 코트 면수 / 타임 수 | 자동 계산값을 직접 고칠 수도 있습니다 |
| 장소 | 코트장을 고르면 자동으로 채워집니다 |
| **반복** | 정기 모임이면 기한까지 한 번에 등록 |

### 정기 모임 한 번에 등록

**반복** 을 고르고 **반복 종료일(기한)** 을 정하면, 그 날짜까지의 모임이
한꺼번에 만들어집니다. 등록 버튼에 **몇 회가 만들어지는지** 미리 나옵니다.

### 일정 보기 세 가지

- **주간 띠** — 오늘부터 7일. 날짜를 누르면 그날 것만
- **목록** — 다가오는 순서대로
- **캘린더** — 한 달 전체

코트장이 여러 곳이면 위쪽 드롭다운으로 골라 볼 수 있습니다.

## 7. 참석 투표

### 7-1. 회원 — 참석/불참 누르기

세 곳 어디서든 누를 수 있습니다.

- **홈**의 다음 모임 카드 — 누르면 바로 반영
- **홈**의 예정 일정 목록 — [참석으로] [불참으로]
- **[일정]** 탭에서 모임을 열고

> **미정은 없습니다.** 일부러 뺐습니다 — 미정이 있으면 확실하지 않은
> 사람이 전부 거기로 몰려서, 총무가 몇 명이 오는지 끝까지 모릅니다.
> 마음이 바뀌면 언제든 다시 누르면 됩니다.

내가 속하지 않은 코트장의 모임에는 참석 체크가 안 됩니다. 대신 왜
안 되는지 화면에 적힙니다.

### 7-2. 운영진 — 아직 안 누른 사람에게 다시 묻기

모임을 열고 **[투표 요청]** 을 누르면, **아직 답하지 않은 사람에게만**
알림이 갑니다. 이미 답한 사람은 안 받습니다.

**자동 발송**도 있습니다 — 모임 N일 전 정해진 시각에 자동으로 나갑니다
(기본 3일 전 오전 9시). **클럽 설정** 에서 며칠 전·몇 시인지 바꿀 수
있습니다.

### 7-3. 앱 없는 회원에게 — 카톡으로 참석 링크 보내기

[투표 요청]은 앱 알림이라 **앱이 없는 회원(오프라인 등록)에게는 닿지
않습니다.** 이분들께는 카톡으로 링크를 보냅니다.

1. **일정** → 모임의 **[명단]** → **[카톡으로 보내기]**
   (오프라인 회원이 있는 모임에만 보입니다. 옆에 미응답 인원이 적힙니다)
2. 공유창에서 **카카오톡** → 받는 사람을 **여러 명 체크** → 보내기
   — 단톡방이 아니라 **각자에게 1:1로** 갑니다. 단톡방에 올려도 됩니다
3. 받은 분이 링크를 누르면 카톡 안에서 페이지가 열립니다.
   **자기 이름 → [참석] / [불참]** 두 번이면 끝
4. 답이 명단에 바로 들어옵니다. 링크로 온 답은 이름 옆에 **🔗** 가 붙습니다
   (총무가 대신 누른 것과 구별됩니다)

- 처음 이름을 고르면 **"○○ 님이 맞나요?"** 를 한 번 더 묻습니다
- 한 번 이름을 고르면 **그 폰이 기억**해서, 다음 링크부터는 바로 참석/불참만 누르면 됩니다
- **이름을 잘못 골랐다면** 화면 위 **[내가 아니에요]** — 그 이름으로 누른 답을
  **누르기 전 상태로 되돌려 줍니다** (원래 답이 있었으면 그 답으로, 없었으면 미응답으로).
  한 폰을 둘이 같이 쓰는 경우를 위해 "그대로 둘게요"도 있습니다
- 링크 하나로 다가오는 모임 4개까지 한꺼번에 답할 수 있습니다
- 링크에는 **앱 없는 회원 이름만** 나옵니다. 앱 회원의 참석은 링크로 바꿀 수 없습니다
- 링크가 엉뚱한 곳에 퍼졌으면 같은 자리의 **링크 새로 만들기** — 옛 링크는 그 순간 막힙니다

카카오 친구 목록과 자동으로 짝지어 보내는 것은 **카카오 정책상 불가능**합니다
(카카오는 우리 앱에 카카오로 로그인한 친구만 목록에 내주는데, 앱 없는
회원은 거기 없습니다). 그래서 카카오톡의 "받는 사람 고르기"를 씁니다.

### 7-4. 게스트 넣기

모임 화면에서 게스트를 직접 추가할 수 있습니다. 게스트도 대진에 잡히고
전적이 남습니다.

## 8. 대진 짜기 (회장·총무·운영진)

**[대진] 탭** → 코트장·날짜를 고르면 그 모임의 대진 화면이 열립니다.

### 8-1. 편성 방식 두 가지

| 방식 | 언제 쓰나 |
|---|---|
| **일반 편성** | 평소 정기 운동. 클럽 규칙(잡복 금지·커플·실력 매칭)을 적용 |
| **KDK (개인전)** | 개인 순위를 가리는 날 |

### 8-2. 경기 방식

**[경기 방식 설정]** 을 누르면 나옵니다.

| | 설명 |
|---|---|
| 복식 | 모든 타임 복식 (코트당 4명) |
| 단식 | 모든 타임 단식 (코트당 2명) |
| 혼합 | 타임마다 복식/단식을 직접 지정 |

### 8-3. 편성 기준 — 위에 있는 것부터 지킵니다

**[더보기] → 클럽 운영 → 대진 설정** 에서 순서를 끌어서 바꿉니다.

1. **출전 인원 최대화** — 가능한 많은 사람이 코트에 서도록
2. **게임 수 균등 배분** — 적게 뛴 사람 우선, 남복/여복 횟수도 맞춤
3. **페어 중복 방지** — 지난 모임 기록까지 봐서 같은 짝을 피함
4. **타임별 희망 패턴** — 홀수 타임 남복+여복 / 짝수 타임 혼복
5. **휴식 우선점수** — 지난주 많이 쉰 사람에게 총무가 준 점수

**커플·고정 페어** 는 따로 등록합니다 (**[더보기] → 클럽 운영 → 커플·고정 페어**).

### 8-4. 대진 만들기

**[대진 자동 작성]** 을 누르면 표가 만들어집니다.

인원이 모자라면 **무엇이 몇 명 부족한지** 알려 주고, 거기서 바로
**게스트 모집글**을 올릴 수 있습니다 (필요한 성비까지 채워진 상태로).

### 8-5. 손으로 고치기

**[수기 편집]** 으로 사람을 끌어다 옮길 수 있습니다. 같은 타임에 두 번
들어가면 막아 줍니다.

참석자가 바뀌면 **"대진과 명단이 다릅니다"** 라고 알려 주고, 빠진 사람이
들어간 경기만 골라서 고칠 수 있습니다.

### 8-6. 결과 입력 — 뛴 사람이 넣고, 상대 팀이 확인

점수는 **그 경기를 뛴 사람이** 넣습니다. 총무가 18경기를 다 받아 적을
필요가 없습니다.

1. 경기가 끝나면 두 팀 중 **아무나 한 명**이 표에서 그 경기를 누르고
   점수를 넣습니다 → **[확인 요청]**
2. **상대 팀**에게 "점수 확인 요청" 알림이 갑니다. 대진 화면 맨 위에도
   **"확인해 주세요"** 가 뜹니다
3. 상대 팀이 **[맞습니다]** 를 누르면 **확정**. 랭킹·전적에 반영됩니다
   - 점수가 다르면 **[아니요]** — 넣은 사람에게 "다시 넣어 주세요" 알림이 갑니다

지켜지는 것
- **그 경기에 뛴 사람만** 넣고 확인할 수 있습니다. 운영진이라도 자기가
  뛴 경기는 똑같이 상대 확인을 받습니다
- **넣은 본인과 같은 팀 동료는 확정할 수 없습니다** — 반드시 상대 팀
- **확정된 점수는 회원이 고칠 수 없습니다.** 고칠 일이 있으면 운영진이
  경기를 눌러 수정합니다(**운영진 수정** — 바로 확정됩니다)
- 이 규칙은 화면만이 아니라 서버의 보안 규칙에서도 막혀 있습니다

상대 팀이 전부 **오프라인 등록 회원**(앱을 안 쓰는 사람)이면 확인을 눌러
줄 사람이 없습니다. 이때는 운영진이 대신 확정합니다.

확인 전 점수는 랭킹에 들어가지 않습니다 (모임 등록 때 "랭킹에 반영"을
껐으면 확정돼도 안 들어갑니다).
