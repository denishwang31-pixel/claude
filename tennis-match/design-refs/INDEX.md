## ⚠️ 반영 전에 사람이 정해야 할 것

시안에 **지금 앱에 없는 기능**과 **사실이 아닌 숫자**가 섞여 있다.
그림으로는 멋있지만 그대로 옮기면 거짓말이 된다. 반영할 때 하나씩
"뺄까 / 만들까 / 실제 값으로 바꿀까"를 정해야 한다.

### 없는 기능을 있는 것처럼 그린 것

| 시안 | 실제 | 어느 화면 |
|---|---|---|
| 전국 520+ 테니스 클럽 운영 중 | 사실이 아닌 숫자 | 로그인 |
| 실명 인증 매칭 · 매너 점수제 | 둘 다 없음 | 로그인 |
| NTRP 등급제 · 실력별 클럽 | NTRP 화면은 있으나 "등급제"는 아님 | 로그인 |
| 코트 알림 · 실시간 빈자리 | 코트 검색은 있으나 빈자리 알림 없음 | 로그인 |
| 케미 85% (파트너 궁합) | 없음 | 홈 |
| 재투표 독려톡 발송 / 카톡 알림 | 카카오 알림톡 미계약 (PRE-LAUNCH D) | 홈·회비 |
| 스마트 자동 입금 대사 "실시간" | 입금 대사는 있으나 붙여넣기 방식, 실시간 아님 | 회비 |
| 은행 복사내역 자동(방금 4건) 자동 승인 | 자동 승인 없음 | 회비 |
| 장부 PDF 내보내기 | 없음 (결산 화면은 있음) | 회비 |
| 총무 전용 응답 독려 알림 · 독려 전송 | 푸시는 있으나 "독려 전송" 버튼은 없음 | 일정 |
| 참석자 얼굴 아바타 (+11) | 프로필 사진 기능이 없음 | 일정 |
| 대기 1명 / 선착순 정원 마감 | 대기자 줄서기 없음 | 일정 |
| 아이디 찾기 | 이 앱은 이메일 로그인이라 아이디가 없음 | 로그인 |

### 자산이 필요한 것

- **코트 사진 히어로** — 시안은 googleusercontent 링크를 건다. 스토어
  앱 첫 화면을 남의 서버 사진에 걸 수 없다(느리고, 오프라인이면 비고,
  저작권도 확인해야 한다). 쓰려면 **저작권이 정리된 이미지 파일**을
  받아 `assets/` 에 넣어야 한다.
- **엠블럼 로고** — 지금 로고 파일이 없다(테니스공 아이콘을 쓴다).
- **글꼴** (Plus Jakarta Sans / Inter) — 둘 다 한글 글리프가 없다.
  한글 화면에서 영문만 다른 글꼴이면 어색하다. 한글까지 덮는 글꼴
  (Pretendard 등) 파일을 함께 받아야 넣을 수 있다.

### 그 밖에 정할 것

- **소셜 버튼 3종 표시** — 시안은 카카오·Apple·네이버를 모두 그린다.
  지금 실제로 도는 것은 구글뿐이다. "준비 안 된 버튼은 그리지 않는다"는
  규칙(`src/lib/social.js`)을 유지할 생각이다 — 눌러도 안 되는 버튼이
  제일 나쁘다. 바꾸려면 말씀해 주실 것.
- **DESIGN.md 안에서 색이 서로 다르다** — 앞머리 YAML(`surface: #faf8ff`
  보랏빛 계열)과 본문 설명(`#F8FAFC` 슬레이트 계열)이 다르다. 지금까지
  본문 설명을 기준으로 삼았다. 계속 그럴지 확인 필요.
- **시안의 데이터는 전부 가짜다** (김민준·과천스매시·9월 23일…).
  실제 화면은 Firestore 에서 오는 값으로 그려야 한다. 시안 코드를
  그대로 붙여넣으면 참석 투표·대진 생성·회비 집계가 전부 날아간다.
  **가져올 것은 생김새이고, 데이터는 지금 것을 그대로 쓴다.**

## 반영할 때 순서 (제안)

1. 로그인 — 이미 v4 로 절반쯤 와 있다. 시안 v2 에 맞춰 마무리
2. 홈 — 히어로 카드(다음 모임 + 참석 버튼) + 퀵타일 + 성적 요약
3. 일정 — 주간 날짜 띠 + 오늘 카드 + 종류별 필터(정기/대회/게스트)
4. 대진표 — 내 경기 포커스 + 코트 현황판
5. 회비 — 총무 장부. 가장 복잡하고, 없는 기능이 가장 많이 섞여 있다
