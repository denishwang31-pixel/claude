# 🔧 사용자 직접 수행 가이드 (코드 외 수동 절차)

> 코드는 전부 준비되어 있습니다. 아래는 **계정·키·콘솔 설정** 등 본인만 할 수 있는 절차입니다.
> 순서대로 진행하면 됩니다. ⏱ 표시는 대략 소요 시간.

## 1. Firebase 프로젝트 연결 (⏱ 15분) — 필수, 가장 먼저

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `tennis-match`)
2. 프로젝트 설정(⚙️) → 일반 → **앱 추가 → 웹(</>)** 선택 → 앱 등록
3. 표시되는 `firebaseConfig` 값 6개를 **`firebaseConfig.js`** 에 복사
   (apiKey / authDomain / projectId / storageBucket / messagingSenderId / appId)
4. 좌측 **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3`, 프로덕션 모드)
5. 좌측 **빌드 → Authentication → 시작하기** → **로그인 방법** 탭에서 2가지 사용 설정
   - **이메일/비밀번호** → 사용 설정 (실제 로그인용)
   - **익명** → 사용 설정 (앱의 "계정 없이 체험해보기" 버튼용)
   - ℹ️ 전화번호 인증은 1차에서 제외했습니다. Firebase JS SDK 의 전화 인증은 RN 에서
     recaptcha 웹뷰가 필요한데 그 패키지(expo-firebase-recaptcha)가 지원 종료됐기 때문입니다.
     정식 출시 때 `@react-native-firebase/auth` 로 전환하며 추가합니다(R-1 2차).
6. 터미널:
   ```bash
   npm i -g firebase-tools
   firebase login
   cd tennis-match
   cp .firebaserc.example .firebaserc   # 열어서 YOUR_FIREBASE_PROJECT_ID 를 실제 ID로 교체
   firebase deploy --only firestore:rules
   ```

## 2. 로컬 실행 (⏱ 10분)

```bash
cd tennis-match
npm install
npm run test:engine      # 대진 엔진 검증 (Firebase 불필요)
npm run test:tournament  # 대회 엔진 검증
npm run test:schedule    # 운영 시간·타임 계산 검증
npm run test:rules       # 보안 규칙 검증 (Java 17+ 필요, 에뮬레이터 자동 실행)
npx expo start          # QR → Expo Go
```
- ⚠️ **푸시 알림은 Expo Go 에서 동작하지 않습니다**(안드로이드 SDK 53+). 앱 흐름 확인만 Expo Go로 하고,
  푸시까지 보려면 4번의 dev build 를 쓰세요.

## 3. Cloud Functions 배포 (⏱ 20분) — 푸시·날씨의 서버측

1. Firebase 콘솔 → 좌측 하단 **요금제 업그레이드 → Blaze(종량제)**
   - 카드 등록만 필요. 이 규모(클럽 수십 명)는 **무료 쿼터 내**라 실제 청구 0원 예상.
2. 기상청 키 발급: https://www.data.go.kr 가입 →
   **"기상청_단기예보 ((구)_동네예보) 조회서비스"** 검색 → 활용신청(즉시 승인) →
   마이페이지에서 **일반 인증키(Decoding)** 복사
3. 터미널:
   ```bash
   cd tennis-match
   firebase functions:secrets:set KMA_SERVICE_KEY   # 위 키 붙여넣기
   cd functions && npm install && cd ..
   firebase deploy --only functions
   ```

### 4-2. iOS — **APK 같은 건 없습니다**

APK 는 안드로이드 전용 형식이고, iOS 는 애플이 앱 파일(.ipa)을 아무 폰에나 설치하지 못하게 막아둡니다.
따라서 아이폰에 넣으려면 **Apple Developer 계정($99/년)이 사실상 필수**입니다.

| 방법 | 비용 | 인원 | 설명 |
|---|---|---|---|
| **TestFlight** (권장) | $99/년 | 내부 100명 / 외부 1만명 | 링크 초대로 설치. 정식 출시 전 베타 배포의 표준 |
| Ad Hoc 배포 | $99/년 | 100대/년 | 기기 UDID 를 하나하나 등록해야 해서 번거로움 |
| iOS 시뮬레이터 빌드 | 무료 | — | **맥 + Xcode 시뮬레이터에서만** 실행. 실제 아이폰 불가 |
| Expo Go | 무료 | 무제한 | 별도 앱 설치 아님. 앱 흐름만 확인 가능, 푸시 불가 |

```bash
eas build --profile preview-ios-device --platform ios
eas submit --platform ios      # TestFlight 업로드
```

## 남은 개발 결정 1건 — R-1 (전화 인증 스택)

1차 로그인은 **이메일/비밀번호 + 익명(체험)** 으로 구현되어 있습니다. 전화번호 인증은 빠져 있습니다.

이유: Firebase **JS** SDK 의 전화 인증은 RN 에서 recaptcha 웹뷰가 필요한데, 그 역할을 하던
`expo-firebase-recaptcha` 가 Expo SDK 48 에서 지원 종료됐습니다(SDK 51 에서 번들 실패 확인).

전환 계획(정식 출시 전): `@react-native-firebase/auth` + dev build 로 바꾸면 recaptcha 없이
기기 검증으로 전화 인증이 동작합니다. 수정 범위는 `src/lib/auth.js` 의 로그인 함수와
`app/login.jsx` UI 뿐이고, 데이터 계층·화면은 그대로입니다.

지금 APK 테스트는 이메일 가입으로 충분합니다.

# 📱 앱 사용법 — 새로 추가된 기능 (처음 쓰는 분용)

> 아래는 앱을 설치한 뒤 화면에서 하는 일입니다. 개발 지식은 필요 없습니다.
> 모두 **하단 [더보기] 탭** 안에 있습니다.

## A. 처음 한 번만 하는 준비 (총무)

### A-0. 클럽 운영 설정 — **가장 먼저 하세요** ⭐
클럽마다 확보한 코트 면수와 운동 시간이 다르므로, 이것부터 맞춰야 대진표가 제대로 나옵니다.

**클럽을 처음 만들 때**: 클럽 생성 화면에서 바로 입력합니다
(코트 면수 / 시작 시각 / 종료 시각 / 한 타임 길이 → **총 타임 수가 자동 계산**되어 표시됩니다)

**나중에 바꾸려면**: [더보기] → [⚙️ 클럽 설정]
1. **코트 면수**: ＋ / − 버튼으로 조절 (한 면당 4명이 동시에 경기)
2. **운영 시간**: 시작·종료를 `10:00`, `13:00` 형식으로 입력
3. **한 타임 길이**: 20/30/40/45/60분 중 선택
4. 아래에 **자동 계산된 타임표**가 나옵니다
   - 예: 10:00~13:00 · 40분 → `1타임 10:00~10:40`, `2타임 10:40~11:20` … **총 4타임**
5. **잡복 기본 허용** 체크박스 (기본은 해제 = 잡복 금지, 권장)
6. **회비 / 게스트비 / 송금 링크**도 여기서 설정
7. [설정 저장]

> 여기서 정한 값이 **새 모임 등록의 기본값**이 됩니다. 모임마다 코트나 시간이 다르면
> 일정 탭의 모임 등록 화면에서 그 모임만 따로 수정하면 됩니다.
> ([클럽 기본값] 칩을 누르면 설정값으로 되돌아갑니다)

### A-0-2. 코트장이 여러 곳이면 등록 (선택)
한 클럽이 여러 코트장을 쓰는 경우 [더보기] → [🏟 코트장 관리]
1. **[+ 코트장 추가]**
2. **이름 / 면수 / 시작·종료 시각 / 타임 길이** 입력
3. **리드 담당자**: 그 코트장 운영을 맡는 회원을 선택 (미지정 가능)
4. 주소는 선택 사항
5. [추가] — 등록하면 요약이 보입니다: `10:00~13:00 · 3면 · 40분/타임 → 4타임`

> 모임을 등록할 때 **[코트장 선택]** 칩이 뜨고, 고르면 그 코트장의 면수·시간·타임 수가 자동으로 채워집니다.
> 코트장이 한 곳뿐이면 등록하지 않아도 됩니다(클럽 설정의 기본값 사용).

### A-0-3. 대진 기본 방식 정하기
[더보기] → [🎯 대진 설정] — 여기서 정한 값이 **모든 모임의 기본**이 됩니다.
1. **기본 타임 유형** 4가지 중 선택
   - **혼복** (기본): 남녀 2:2
   - **남복/여복**: 동성 복식만
   - **단식**: 1:1 (코트당 2명)
   - **자동**: 홀수 타임 동성복식 / 짝수 타임 혼복 (예전 방식)
2. **NTRP 실력 매칭** 체크 — 켜면 비슷한 실력끼리 같은 코트에 배정하고, 양 팀 실력 합이 비슷해지도록 팀을 나눕니다
   (NTRP 미설정 회원은 조(A/B/C)로 대신 계산)
3. **잡복 기본 허용** 체크 (기본 해제 권장)
4. **편성 기준 우선순위**: ▲▼ 로 순서 변경 (대진 탭의 드래그와 같은 설정)
5. [기본 설정 저장]

### A-1. 회원들 구력(테니스 시작일) 입력
1. [더보기] → [👥 회원]
2. 회원 이름을 누르면 편집창이 열립니다
3. **테니스 시작일**에 `2019-03` 처럼 입력 → [저장]
   - 정확한 날짜를 모르면 연-월만 입력해도 됩니다 (`2019-03` → 3월 1일로 저장)
   - 대회 나갈 때 "구력 3년 이하부" 같은 참가 자격을 확인하는 기준이 됩니다
   - 회원 본인도 자기 것은 직접 수정할 수 있습니다

### A-2. 커플·고정 페어 등록 (해당되는 경우만)
1. [더보기] → [💑 커플·고정 페어]
2. 위에서 **커플** 또는 **고정 페어** 선택
   - **커플**: 부부·커플처럼 같이 오고 같이 가야 하는 사이
     → 두 사람이 항상 같은 타임에 함께 뛰거나 함께 쉽니다. 한 명만 일찍 나와서 기다리는 일이 없어집니다.
     (같은 편일 필요는 없습니다. 서로 상대편이 될 수도 있습니다)
   - **고정 페어**: 대회 준비로 항상 같은 편이어야 하는 조합
     → 항상 한 팀으로 묶여서 대진이 나옵니다
3. 아래 회원 목록에서 **두 명을 탭** → [등록] 버튼
4. 잘못 등록했으면 목록에서 [삭제]

> ⚠️ 한 사람은 하나의 커플/페어에만 등록할 수 있습니다(대진 편성이 불가능해지는 것을 막기 위해서입니다).
> 등록해두면 이후 **대진 생성할 때 자동으로 반영**됩니다. 대진 탭 상단에 "적용 제약: 커플 2쌍…"이라고 표시됩니다.

## B. NTRP 등급 관리

[더보기] → [📊 NTRP 등급]. 탭이 3개입니다.

### B-1. 기준 안내 (먼저 읽어보세요)
- 2.0~5.0까지 7단계가 있고, 각 단계를 누르면 **체크리스트**가 펼쳐집니다
- 예: 3.0은 "포핸드 랠리가 안정적 / 백핸드는 되지만 일관성 부족 / 첫 서브 성공률 50% 내외"
- **대부분 해당되는 가장 낮은 등급**을 고르는 것이 관행입니다 (보수적으로 잡기)

### B-2. 내 등급 (회원 각자)
- **셀프 평가**: 숫자를 눌러 본인 등급 선택. 언제든 수정 가능
- 아래에 나에 대한 **회원 투표 결과**(중앙값)가 보입니다. 누가 몇 점 줬는지는 안 보입니다

### B-3. 클럽 등급표 (투표 / 인증)
- 회원을 누르면 **그 사람 등급에 투표**할 수 있습니다 (본인 제외)
- **총무·운영진**은 같은 화면에서 **인증 등급을 확정**할 수 있습니다
- 최종 표시 등급 우선순위: **운영진 인증 > 회원 투표(중앙값) > 셀프 평가**
  - 즉 운영진이 인증하면 그 값이 최종값이 되고, 인증 전에는 회원들 투표 중앙값이 쓰입니다

## C. 출석 관리

[더보기] → [✅ 출석]. 탭이 2개입니다.

### C-1. 출석 체크 (모임 끝난 뒤, 총무)
1. 위쪽에서 날짜 선택 (최근 5개 모임)
2. 회원별로 [출석] / [결석] 버튼을 누릅니다
3. 편하게 하려면 **[참석자 일괄 출석]** 버튼 → "참석" 의사를 밝힌 사람 전원이 출석 처리됨
   → 그다음 안 온 사람만 [결석]으로 바꾸면 됩니다

### C-2. 출석률 통계 (전원 조회 가능)
- 회원별 출석률(%)이 막대와 함께 표시됩니다 (70% 이상 초록, 40% 미만 빨강)
- **노쇼**: "참석한다"고 해놓고 안 온 횟수 — 회비·페널티 논의할 때 근거가 됩니다

## D. 대회 운영 (핵심)

[더보기] → [🏆 대회]

### D-1. 대회 개설 (총무)
1. **[+ 새 대회 개설]**
2. **대회 정보**: 대회명, 날짜 입력
3. **진행 방식**:
   - ☑️ **예선 조별리그 진행** — 체크하면 조별리그 후 토너먼트
     - **조 개수**(예: 4) / **조별 진출 팀**(예: 2 → 각 조 1·2위가 본선 진출)
   - ☐ 체크를 **해제**하면 **곧바로 토너먼트만** 진행합니다
4. **참가자 선택**: 참가할 회원 이름을 모두 탭 (최소 4명)
5. **팀 구성 방식**:
   - **NTRP 균등**: 잘하는 사람 + 덜 잘하는 사람을 묶어 팀 실력을 비슷하게 (추천)
   - **무작위**: 랜덤 배정
6. **시드 배정**(선택): 구성된 팀 목록에서 강팀 옆에 `1`, `2`… 입력
   - 시드를 주면 강팀끼리 **초반에 만나지 않도록** 자동으로 분산 배치됩니다
   - 예선을 하면 시드 팀들이 서로 다른 조로 갈라지고, 토너먼트에서는 1번 시드와 2번 시드가 결승에서야 만나게 배치됩니다
   - 비워두면 무작위입니다
7. **[대회 개설]**

### D-2. 예선 진행
- 조별로 순위표와 경기 목록이 나옵니다
- 경기 옆 **[입력]** → 점수 두 칸 입력 → [저장]
- 순위는 **승수 → 득실차 → 다득점** 순으로 자동 정렬됩니다
- 진출권(예: 상위 2팀)은 순위 번호가 **연두색**으로 표시됩니다
- 예선 경기를 **모두 입력**하면 아래 버튼이 활성화됩니다 → **[예선 종료 → 본선 대진 생성]**

### D-3. 본선 토너먼트
- 8강 → 준결승 → 결승 순으로 대진표가 자동 생성됩니다
- 참가 팀이 8팀, 16팀처럼 딱 떨어지지 않으면 **상위 시드에게 부전승**이 자동 배정됩니다 ("부전승" 표시)
- 경기마다 [입력] → 점수 저장 → **승자가 다음 라운드로 자동 진출**
- 결승까지 입력하면 상단에 **🏆 우승 팀**이 표시되고 대회가 "종료" 상태가 됩니다

### D-4. 기록 보관
- 대회 목록에서 **진행 중 / 지난 대회 기록**이 나뉘어 보입니다
- 지난 대회를 누르면 그때의 조별 순위·토너먼트 결과를 그대로 다시 볼 수 있습니다

## D-5. 대회를 실력 그룹으로 나눠 진행하기
대회 개설 화면에서 **[수준별 그룹으로 진행]** 을 체크하면 토너먼트 대신 실력 그룹제로 운영합니다.
1. **그룹별 정원**을 쉼표로 입력 — 예: `8,8,6` (앞쪽이 상위 그룹)
2. **[자동 배정]** → 참가자를 **남·여 각각 NTRP 순서로** 그룹에 배분합니다
   - 각 그룹의 성비가 전체 성비와 비슷하게 유지됩니다
   - 그룹마다 `NTRP 3.5~4.5` 처럼 실력 범위가 표시됩니다
3. **수동 조정**: 회원 이름을 누르면 다음 그룹으로 이동합니다 (누를 때마다 A→B→C→A 순환)
4. [대회 개설] — 이후 대회 상세 화면에서 그룹별 명단을 보고 그룹 안에서 자유롭게 시합을 진행합니다
   (운영진은 여기서도 이름을 눌러 그룹을 바꿀 수 있습니다)

> 정원 합이 실제 참가 인원과 달라도 됩니다. 모자라면 마지막 그룹이 늘어나고, 남으면 자동으로 줄어듭니다.

## E. 타임별로 경기 유형 바꾸기

대진 탭에서 **[타임별 경기 유형]** 카드를 보면 타임마다 칩이 4개씩 있습니다.
- 기본값은 [🎯 대진 설정]에서 정한 유형이고, **여기서 특정 타임만 다르게** 바꿀 수 있습니다
- 예: `1타임 혼복 · 2타임 남복/여복 · 3타임 단식 · 4타임 혼복`
- 오른쪽 위 **[✓ 실력매칭]** 칩으로 이 모임만 실력 매칭을 켜고 끌 수 있습니다
- 바꾼 뒤 **[대진 재생성]** 을 눌러야 반영됩니다

> **단식 타임**은 코트당 2명이 들어갑니다(남단식/여단식 자동 구분). 4면이면 8명이 동시에 경기하므로,
> 인원이 많을 때 대기 인원이 늘어납니다. 반대로 인원이 적을 때 유용합니다.

## F. 인원이 안 맞을 때 — 잡복 경고창

대진 생성 버튼을 누르면 **참석 인원의 성비를 자동으로 검사**합니다.
기본 원칙은 **잡복 금지**(남복=남4 / 여복=여4 / 혼복=남2여2 만 허용)입니다.

### E-1. 생성 전에 미리 보기
대진 탭 상단에 현재 상태가 항상 표시됩니다:
- `✓ 3면 모두 잡복 없이 편성 가능` — 그냥 생성하면 됩니다
- `△ 잡복 없이 1면만 가능 (3면 사용하려면 여성 4명 추가)` — 아래 경고창이 뜹니다
- `⚠ 인원 부족 — 1면 진행에 여성 1명 더 필요` — 생성이 불가능합니다

### E-2. 경고창 3종류

**① 일부 코트만 사용 가능할 때**
```
일부 코트만 사용됩니다
현재 참석 8명 (남 5 · 여 3) · 확보 코트 2면
 ▸ 잡복 없이: 1면만 사용 (나머지는 대기)
 ▸ 2면 모두 쓰려면: 여성 1명 추가 필요
 ▸ 잡복을 허용하면: 2면까지 사용 가능
잡복(남3여1 등)을 허용하시겠습니까?
     [아니오 (잡복 없이)]   [예, 잡복 허용]
```
- **아니오** → 1면만 쓰고 나머지 인원은 그 타임에 쉽니다
- **예** → 2면을 모두 쓰고, 남는 성비는 잡복으로 편성합니다

**② 잡복 없이는 아예 안 될 때** (예: 남 3명 · 여 1명)
```
잡복 없이는 편성할 수 없습니다
 ▸ 잡복 없이 하려면: 남성 1명 추가 필요   ← 남자 1명 더 오면 남복 가능
 ▸ 잡복을 허용하면: 지금 인원으로 1면 진행 가능
잡복(남3여1 등)을 허용하시겠습니까?
            [아니오]   [예, 잡복으로 편성]
```

**③ 잡복을 허용해도 불가능할 때** (4명 미만이거나 성비가 극단적일 때)
```
대진표를 만들 수 없습니다
현재 참석 3명 (남 2 · 여 1)
복식 한 경기에는 4명이 필요합니다.
 ▸ 최소 1면이라도 진행하려면
   여성 1명이 더 필요합니다.
                                    [확인]
```
→ 이 경우엔 **몇 명이 더 필요한지 정확히 알려주므로**, 게스트를 부르거나 참석자를 더 모으면 됩니다.

### E-3. 잡복으로 만든 대진표
- 해당 경기에 **`잡복`** 이라는 표시가 붙습니다
- 잡복은 **최후 수단**이라 정규 조합(남복·여복·혼복)으로 채울 수 있는 코트는 그대로 정규로 편성되고,
  남는 인원만 잡복으로 묶입니다
- 팀은 성비가 최대한 균형이 되도록 나눕니다 (남3여1이면 `남2 vs 남1여1`)
- 매번 묻는 게 번거로우면 [더보기] → [⚙️ 클럽 설정] → **잡복 기본 허용**을 체크하세요

## G. 자주 묻는 상황

| 상황 | 해결 |
|---|---|

| 특정 타임만 단식으로 하고 싶음 | 대진 탭 → [타임별 경기 유형]에서 그 타임만 [단식] 선택 후 재생성 |
| 실력 차이가 너무 남 | [대진 설정] 또는 대진 탭의 [실력매칭] 칩을 켜세요. NTRP가 없는 회원은 조(A/B/C)로 계산됩니다 |
| 대회를 실력별로 나누고 싶음 | 대회 개설 시 [수준별 그룹으로 진행] 체크 → 그룹 정원 입력 → [자동 배정] |

# 🔄 앱 업데이트 방법 (코드가 바뀌었을 때)

새 기능이 추가되면 **APK를 다시 만들어 설치**해야 합니다. PC에서 아래 순서로 진행하세요.

## 1) 최신 코드 받기

**git clone 으로 받았다면:**
```cmd
cd C:\Users\denis\claude
git pull
cd tennis-match
npm install
```

**ZIP 으로 받았다면:** 새로 ZIP을 내려받아 압축을 풀고, **기존 `firebaseConfig.js` 와 `.firebaserc` 를 새 폴더로 복사**한 뒤 `npm install`

> ⚠️ `firebaseConfig.js` 는 본인 키가 들어있어 저장소에 없습니다. 덮어쓰지 않도록 주의하세요.

## 2) 보안 규칙 다시 배포 (규칙이 바뀐 경우)
```cmd
firebase deploy --only firestore:rules
```

## 3) APK 다시 빌드
```cmd
eas build --profile preview --platform android
```
- 10~20분 뒤 새 다운로드 링크가 나옵니다
- **기존 앱 위에 그대로 설치**하면 됩니다(데이터 유지). 삭제 후 재설치도 데이터는 서버에 있어 안전합니다
- 버전을 올리고 싶으면 `app.json` 의 `version`, `android.versionCode` 를 수정하세요

## 4) 직접 다운로드 링크 뽑기 (Install 버튼이 안 될 때)
```cmd
eas build:list --platform android --limit 1
```
출력의 `Artifact: https://expo.dev/artifacts/eas/....apk` 를 폰으로 보내면 됩니다.

# 🧪 새 기능 사용법 (2차 업데이트)

## 운영진 / 회원 모드 전환 — 테스트용 ⭐
홈 화면 상단(초록 헤더)에 **[내 역할] [운영진 모드] [회원 모드]** 버튼이 있습니다(운영진에게만 보임).
- **회원 모드**로 바꾸면 일반 회원이 보는 화면 그대로 확인할 수 있습니다
  (대진 편성 버튼 사라짐, 회비 메뉴 사라짐, 홈에 내 그룹 일정만 표시)
- 다시 **[내 역할]** 을 누르면 원래대로 돌아옵니다

## 역할(운영진) 임명
[더보기] → [👥 회원] → 회원 이름 클릭 → 맨 아래 **역할** 에서 선택
- **회장 / 총무 / 책임리더 / 회원** 중 선택, 인원 제한 없음
- **회장만 임명할 수 있습니다**(클럽을 만든 사람이 자동으로 회장)
- 회장을 넘기려면 상대를 회장으로 임명한 뒤 본인 역할을 바꾸세요

## 정기 모임 한 번에 등록
[일정] → **[+ 새 모임]** → 날짜(📅)·시간(🕐) 선택 → 아래 **반복** 에서
- **매주 / 격주 / 매월 같은 주·요일** 중 선택
- **반복 종료일(기한)** 지정 → 아래에 `일요일 10:00 · 총 12회 생성` 미리보기
- **[정기 모임 등록]** → 확인창에서 개수 확인 후 등록 (한 번에 생성)

## 참석 체크 (테스트/현장 대응)
[일정] → 모임 카드 하단(운영진에게만 보임)
- 회원 이름을 누르면 **참석 ↔ 불참** 전환
- **[전원 참석]** 으로 한 번에 처리 → 대진 생성 테스트가 쉬워집니다

## 회원 정보 수정·삭제
[더보기] → [👥 회원] → 이름 클릭
- 이름·**성별**·조(**선택 안함** 가능)·구력·상태(활동/휴면/탈퇴) 수정
- **[회원 삭제]** (본인은 삭제 불가)
- **정기 운동 그룹(코트장)** 지정 → 그 회원 홈에는 이 그룹 일정만 표시됩니다

## 회비·지출 (운영진 전용)
[더보기] → [💳 회비·지출]
- 상단에서 **월 납입 / 연 납입** 선택, 기간 선택
- **수입 / 지출 / 잔액** 요약이 상단에 표시
- **[회비 납부]** 탭: 이름을 눌러 납부/미납 전환, 은행 내역 붙여넣기 일괄 매칭
- **[지출 관리]** 탭: **[+ 지출]** → 날짜·항목·금액·메모 입력
- 일반 회원에게는 이 메뉴가 아예 보이지 않습니다

## 용품 / 원포인트 (하단 탭)
- **🛍 용품**: 카테고리(라켓·의류·신발·소모품·가방·기타) 필터, 누르면 구매처로 이동
  - **앱 운영자만** 등록·삭제할 수 있습니다. 클럽 회장·총무도 보기만 가능 (아래 3차 업데이트 참고)
  - 용품 목록은 **앱을 쓰는 모든 클럽이 똑같이** 봅니다
- **🎯 원포인트**: 영역별(포핸드·백핸드·발리·서브 등) 유튜브 영상
  - 클럽 운영진: **[+ 추가]** → 유튜브 링크 붙여넣으면 **썸네일이 자동으로** 표시됩니다
- 홈 화면의 **광고 배너**는 용품에 등록한 항목이 자동으로 순환 노출됩니다

- 새로 만든 클럽에서는 본인이 **회장**이 됩니다

# 🆕 3차 업데이트 사용법

## 1. 홈 — 코트별 보기 + 모드 3종

홈 상단에 **[내 역할] [운영진] [리드] [회원]** 버튼이 생겼습니다(운영진에게만 보임).
회원 화면이 실제로 어떻게 보이는지 직접 눌러 확인할 수 있습니다.

| 모드 | 보이는 일정 |
|---|---|
| **운영진** | 클럽에 등록된 **모든 코트장**의 일정 |
| **리드** | 내가 **책임리더로 지정된 코트장**의 일정만 |
| **회원** | 내가 **소속된 코트장** + 게스트로 확정된 일정만 |

- 볼 수 있는 코트장이 2곳 이상이면 상단에 **코트 드롭다운**이 나타납니다. 고르면 그 코트 일정만 남습니다.
- 코트장 등록: [더보기] → **[🏟 코트장 관리]** → 코트명·면수·시간 + **책임리더 지정**
- 회원의 소속 코트 지정: [더보기] → **[👥 회원]** → 회원 선택 → 소속 코트장 체크

## 2. 홈에서 대진표로 바로 이동
- 홈 맨 위 **다음 모임 카드**를 누르면 → 그 모임의 **대진표**가 바로 열립니다
- 운영진 화면의 **[전체 코트 현황]** 목록에서 아무 줄이나 눌러도 같은 방식으로 이동합니다

## 3. 대진 탭 — 일정이 여러 개일 때 (이전 문제 수정)
> 이전에는 가장 가까운 모임 1건만 잡혀서 **첫 경기 대진만** 보였습니다. 이제 고칠 수 있습니다.

- 대진 탭 맨 위: **코트 드롭다운** → 그 아래 **날짜 가로 스크롤**
- 날짜 칩에 그 회차의 **참석 인원 수**와, 대진이 이미 만들어졌으면 **✓** 표시가 뜹니다
- 코트를 바꾸면 날짜 목록도 그 코트 것으로 새로 채워집니다
- 여러 코트를 맡은 운영진·리드는 **코트를 바꿔가며 각각 편성**하면 됩니다

## 4. 대진표 보기 — 한눈에 보는 표
대진표 오른쪽 위 **[표] / [목록]** 으로 전환합니다. 기본은 **표**입니다.

**① 대진표 (가로=코트, 세로=타임)**
- 한 칸 = 한 경기. 경기 유형(혼복/남복/여복/잡복/단식)이 **색깔 배지**로 구분됩니다
- 스코어를 넣으면 **이긴 팀 이름이 굵은 초록**으로 바뀝니다
- 칸을 누르면 그 경기 **스코어 입력창**이 아래에 열립니다 (운영진만)
- 코트가 많으면 표를 **좌우로 밀어서** 봅니다

**② 참석자 경기 현황 (가로=타임, 세로=사람)**
- 동그라미 안 숫자 = **그 타임에 배정된 코트 번호**, 회색 **"휴"** = 그 타임 휴식
- 맨 오른쪽 **합계** = 그 사람의 총 경기 수. 경기가 가장 많은 사람은 초록, 가장 적은 사람은 주황으로 표시됩니다
- 표 아래에 `최다 5경기 / 최소 3경기` 또는 `전원 4경기 균등`이 요약으로 나옵니다 — **편성이 공평한지 바로 확인**할 수 있습니다

## 5. 게스트 모집 = 공개 게시판
메뉴가 정리됐습니다.

| 메뉴 | 범위 |
|---|---|
| **🎾 게스트 모집 (공개 게시판)** | **모든 클럽·모든 회원**이 함께 보는 하나의 게시판 |
| **📢 클럽 공지·자유글** | 우리 클럽 회원만 보는 내부 게시판 (기존 "게시판") |

**모집글 올리기 (운영진)**
1. [더보기] → **[🎾 게스트 모집]** → **[+ 모집글]**
2. **우리 클럽 예정 모임**을 하나 고르면 날짜·시간·장소가 자동으로 채워집니다
3. **모집 인원을 남/여로 나눠** 입력 (예: 남 1, 여 1) — 이 숫자로 자동 매칭이 됩니다
4. 지역(예: `경기 과천시`)은 다른 클럽이 검색하는 기준이니 꼭 넣어주세요
5. 게스트비는 클럽 설정의 게스트비가 자동으로 붙습니다

**신청·확정**
- 누구나(다른 클럽 회원 포함) **[참여 의사 개진]** 을 누를 수 있습니다
- 내 성별이 아직 비어 있는 자리면 카드에 **"내 조건 맞음"** 배지가 뜹니다
- 필터: **전체 / 우리 클럽 / 다른 클럽**, 그리고 **지역별** 칩
- 모집한 클럽의 운영진이 신청자 옆 **[확정]** 을 누르면 → 그 모임 **참석자에 자동 추가**되어 대진에 들어갑니다
- 게스트로 뛴 경기 기록은 **본인 계정에 그대로 누적**됩니다

## 6. 앱 운영자(용품 담당) 등록 — 별도 로그인은 없습니다

> **질문: 앱 관리자 모드 로그인 기능이 따로 필요한가요? → 아니요.**
> 계정을 새로 만들 필요 없이, **평소 쓰던 이메일 계정 그대로** 로그인하면 됩니다.
> Firebase에 "이 사람은 앱 운영자" 라는 표시만 한 번 해두면 그 계정에서만 용품 등록 버튼이 나타납니다.
> 비밀번호가 하나 더 생기지 않아 잊어버릴 일도 없고, 앱에 관리자 로그인 화면이 없으니 남이 뚫을 문도 없습니다.

**등록 방법 (한 번만, 3분)**

1. 앱에서 **본인 이메일로 로그인**해 둡니다 (아직 안 했다면 먼저 가입)
2. [Firebase 콘솔](https://console.firebase.google.com) → 내 프로젝트 → 왼쪽 **빌드(Build)** → **Authentication** → **Users** 탭
3. 내 이메일 줄의 **User UID** 를 복사합니다 (`a1B2c3...` 같은 28자 문자열)
4. 왼쪽 **빌드(Build)** → **Firestore Database** → **[+ 컬렉션 시작]**
   - 컬렉션 ID: `appAdmins`
   - 문서 ID: **3번에서 복사한 UID를 그대로** 붙여넣기
   - 필드: `note` (문자열) = `앱 운영자`  ← 아무 값이나 상관없습니다. **문서가 있다는 것 자체가 권한**입니다
   - **[저장]**
5. 앱을 **완전히 껐다가 다시 실행**합니다 (권한은 로그인 시점에 한 번 확인합니다)
6. 🛍 **용품** 탭에 들어가면 헤더에 **"· 앱 관리자 모드"**, 아래에 **[+ 추가]** 버튼이 보입니다

**권한 정리**

| | 용품 보기 | 용품 등록·삭제 |
|---|---|---|
| 앱 운영자 (`appAdmins` 등록) | ✅ | ✅ |
| 클럽 회장·총무·책임리더 | ✅ | ❌ |
| 일반 회원 | ✅ | ❌ |

- 운영자를 더 추가하려면 4번을 그 사람 UID로 반복하면 됩니다
- 권한을 뺏으려면 그 문서를 **삭제**하면 됩니다
- `appAdmins` 문서는 **앱에서는 절대 만들 수 없습니다**(보안 규칙에서 차단). 오직 Firebase 콘솔에서만 가능합니다 — 회원이 스스로 운영자가 될 수 없습니다

> ⚠️ 이번 업데이트에서 용품 데이터가 **클럽별 → 앱 공용**으로 옮겨졌습니다.
> 예전에 등록해 둔 용품이 있다면 목록에서 사라져 보입니다. 앱 운영자 계정으로 **다시 등록**해 주세요.

# 🆕 4차 업데이트 사용법

## 1. 가입할 때 클럽을 꼭 만들지 않아도 됩니다

회원가입 후 화면이 세 갈래로 바뀌었습니다.

| 선택 | 어떻게 되나 |
|---|---|
| **클럽 찾기** | 클럽 이름·지역으로 검색 → **[가입 신청]** → 운영진이 승인하면 자동 입장 |
| **클럽 만들기** | 내가 **회장**이 되어 새 클럽 개설 (기존과 동일) |
| **나중에 할게요 · 먼저 둘러보기** | 클럽 없이 앱 사용. 게스트 모집 게시판·용품을 볼 수 있고, 언제든 [더보기]에서 가입 가능 |

**검색창은 초대코드도 받습니다.** 6자리 코드를 그대로 넣으면 승인 없이 바로 가입됩니다.

### 승인 대기 화면
가입 신청을 하면 대기 화면이 뜹니다.
- 운영진이 승인하는 **즉시 자동으로 입장**합니다. 새로고침할 필요 없습니다
- 앱을 껐다 켜도 대기 화면으로 돌아옵니다
- 신청을 취소하고 다른 클럽을 고를 수도 있습니다

## 2. 가입 신청 승인 (운영진)

[더보기] → **[🙋 가입 신청]**
- 대기 중인 신청이 있으면 메뉴에 **빨간 숫자 배지**가 뜨고, **홈에도 알림 카드**가 표시됩니다
- 신청자의 이름·성별·신청일을 보고 **[승인]** 또는 **[거절]**
- 승인하면 회원 명단에 바로 추가되고, 신청한 분의 앱에서도 그 즉시 입장됩니다
- 초대코드로 들어온 사람은 승인 절차 없이 바로 가입되므로 여기 표시되지 않습니다

## 3. 초대코드는 어디에 쓰는 건가요?

**초대코드 = 초대장 그 자체입니다.** 코드를 아는 사람은 운영진 승인 없이 곧바로 우리 클럽 회원이 됩니다.
그래서 단톡방이나 공개 게시판에 올리지 말고, **초대할 분에게만** 보내세요.
코드를 모르는 사람은 위의 [클럽 검색 → 가입 신청 → 승인] 경로를 씁니다.

### 초대 링크로 보내기
[더보기] → **[✉️ 클럽 초대]**

| 버튼 | 하는 일 |
|---|---|
| **📤 카톡·문자로 초대 보내기** | 공유 시트가 열립니다. 카톡·문자·메일 어디로든 바로 전송 |
| **🔗 링크 복사** | `tennismatch://join?code=ABC234` 링크만 복사 |
| **📋 문구 복사** | 클럽 이름 + 코드 + 링크 + 안내가 들어간 완성된 문구 복사 |
| 코드 숫자를 탭 | 6자리 코드만 복사 |

**받는 사람 입장**
- 앱이 깔려 있으면 → 링크를 누르는 순간 초대 화면이 열리고, 이름만 확인하면 가입 완료
- 앱이 없으면 → 앱 설치 후 [클럽 찾기] 검색창에 코드 입력
- 로그인 전에 링크를 눌러도 → 로그인 후 그 초대로 자동으로 되돌아옵니다

### 공개 목록 노출 켜고 끄기
같은 화면 아래 **[공개 목록 노출]** 스위치가 있습니다.
- **노출 중**: 다른 사람이 클럽 이름·지역으로 검색해 가입 신청할 수 있음
- **숨김**: 초대코드를 아는 사람만 들어올 수 있음

공개되는 정보는 **클럽 이름·지역·회원 수뿐**입니다. 일정·회원 명단·회비는 회원만 볼 수 있습니다.

> 예전 버전에서 만든 클럽은 공개 목록에 아직 없습니다.
> 운영진이 **[✉️ 클럽 초대]** 화면을 한 번 열면 자동으로 등록됩니다.

# 🆕 5차 업데이트 사용법

## 1. 부수(1부~5부) — 대회 자격의 기준

동호인은 실제로 "3부"라고 말하지 NTRP로 말하지 않습니다. 그래서 **부수를 먼저**, NTRP는 참고 지표로 함께 보여줍니다.

| 부수 | 기준 | 대략 NTRP |
|---|---|---|
| 1부 | 선수 출신·상위 입상권 | 4.5~7.0 |
| 2부 | 전국 대회 입상권 | 4.0~4.5 |
| 3부 | 지역 대회 상위권 | 3.5~4.0 |
| 4부 | 동호회 중상위·게임 운영 가능 | 3.0~3.5 |
| 5부 | 동호회 입문~중급 | 2.0~3.0 |
| 오픈부 | 부수 구분 없이 참가 | — |

- 입력: 가입할 때, 또는 [더보기] → [👥 회원] → 이름 탭
- 대회 개설 시 **참가 자격을 "3부 이하"처럼 부수로 제한**할 수 있습니다
- 청백전 팀 나누기와 실력 매칭에도 부수가 반영됩니다 (NTRP가 없으면 부수로 환산)

## 2. 활동 지역 — 시/도 → 시·군·구 선택

예전엔 자유 입력이라 "과천", "경기 과천", "과천시"가 전부 다른 값이 되어 지역 검색이 사실상 동작하지 않았습니다. 이제 **목록에서 고릅니다** (17개 시/도 · 전국 시·군·구).

누르면 안드로이드는 하단 시트가, 아이폰은 액션시트가 올라옵니다. 클럽 검색·게스트 모집 지역 필터가 이 값으로 맞물립니다.

## 3. 구력 확인제도 🔒

**테니스 시작 년월은 한 번 저장하면 본인도 못 바꿉니다.**

대회 참가 자격이 "구력 3년 이하부"처럼 걸려 있어서, 대회를 앞두고 슬쩍 늦추는 걸 막기 위한 장치입니다.
- 잘못 입력했다면 **회장만** [👥 회원] → 해당 회원 → **[초기화]** 로 풀어줄 수 있습니다
- 초기화 후 다시 입력하면 그때부터 또 잠깁니다

## 4. 대회 형식 4종

[더보기] → [🏆 대회] → **[새 대회 개설]** 에서 먼저 형식을 고릅니다.

| 형식 | 언제 쓰나 |
|---|---|
| 🏆 **조별리그 + 토너먼트** | 정식 클럽 챔피언십 |
| 🎯 **KDK 개인전** | 월례대회 (파트너 바꿔가며 개인 순위) |
| 🔵 **청백전** | 클럽을 두 팀으로 갈라 단체전 |
| 🤝 **클럽 교류전** | 다른 클럽과 맞붙기 |

### 청백전
참가자를 고르면 **실력과 성별이 고르게 청팀·백팀으로 자동 분할**됩니다.
- 평균 실력 차가 화면에 표시되고, 0.25 이내면 "✓ 전력이 고르게 나뉘었습니다"
- 선수 이름을 누르면 반대 팀으로 옮겨집니다
- **[다시 나누기]** 로 재분할
- 모든 경기가 청팀 2명 vs 백팀 2명 — 팀 안에서 맞붙는 경기는 생기지 않습니다
- 상단에 **팀 점수판**(이긴 경기 수), 하단에 **오늘의 MVP** 3명

### 클럽 교류전
- A팀은 우리 클럽 참가자, B팀은 **상대 클럽 선수를 직접 등록**(이름·성별·부수)
- 상대 클럽 이름을 넣으면 점수판에 그대로 표시됩니다
- 나머지는 청백전과 동일

## 5. 참가투표 🗳

일정 참석 체크와 **별개**입니다. 회식 날짜, 대회 참가 의사, 유니폼 색처럼 단톡방에서 손으로 세던 것들을 여기서 처리합니다.

[더보기] → **[🗳 참가투표]** (홈 아이콘에도 있음)
- 두 형태: **참가 여부**(참가/미정/불참) 또는 **선택지**(최대 6개 직접 입력)
- 마감일을 넣으면 그 날짜가 지나면 자동 마감
- 득표율이 막대로 채워집니다
- **운영진에게만** 누가 뭘 골랐는지 + **미투표자 명단**이 보입니다
- 진행중 / 마감 탭으로 구분

## 6. 클럽 채팅 💬

[더보기] → **[💬 클럽 채팅]**
- 최근 200개까지 실시간. 그 위쪽 기록은 게시판에 남기세요
- 내 메시지는 오른쪽 초록, 상대는 왼쪽 흰색. 날짜가 바뀌면 구분선
- **길게 눌러 삭제** — 본인 글은 본인이, 운영진은 모든 글
- 보안상 **메시지 수정은 막아뒀습니다**(내용 바꿔치기 방지). 지우고 다시 쓰세요

## 7. 클럽 가입 비밀번호 🔒

초대코드 외에 **클럽 비밀번호**가 하나 더 생겼습니다.

| 방법 | 승인 | 언제 |
|---|---|---|
| 초대 링크·코드 | 불필요 | 한 명씩 콕 집어 초대할 때 |
| **클럽 비밀번호** | 불필요 | 단톡방에 "우리 클럽 비번 1234" 공유할 때 |
| 가입 신청 | **필요** | 모르는 사람이 검색해서 들어올 때 |

- 설정: 클럽 만들 때 입력, 또는 [⚙️ 클럽 설정]
- 비워두면 승인제로만 운영됩니다
- 비밀번호가 있는 클럽은 검색 결과에 **🔒 배지**가 붙고 [비밀번호로 바로 입장] 버튼이 나옵니다

## 8. 클럽 대표 이미지 + 남/여 인원

클럽 검색 결과가 옐로우홀처럼 바뀌었습니다 — **대표 이미지 · 지역 · 남 N / 여 N / 총 N명**.
- 이미지 URL은 클럽 만들 때 또는 [클럽 설정]에서 입력
- 인원은 승인·가입 때 자동으로 갱신됩니다

## 9. 서비스 전체 현황

온보딩 화면과 홈(클럽 없는 상태)에 **클럽 수 · 회원 수 · 누적 경기 수**가 표시됩니다. 클럽이 만들어지고 회원이 가입할 때마다 자동으로 올라갑니다.

## 10. 랭킹 반영 토글

모임 등록 시 **[랭킹에 반영]** 체크박스가 생겼습니다.
- 끄면 그 모임의 경기 결과가 **클럽 랭킹·전적·케미 통계에 들어가지 않습니다**
- 친선 경기, 연습 모임, 게스트 위주 모임에 쓰세요
- 일정 목록에 "· 랭킹 미반영"으로 표시됩니다

## 📱 화면이 달라진 점 — 플랫폼 표준 컴포넌트

같은 앱인데 **안드로이드와 아이폰에서 다르게 보입니다.** 각 OS가 정한 규칙(Material Design 3 / Human Interface Guidelines)을 따르도록 만들었기 때문입니다.

| | 안드로이드 | 아이폰 |
|---|---|---|
| 버튼 누를 때 | 물결처럼 퍼지는 잉크 효과 | 살짝 흐려짐 |
| 버튼 모양 | 양끝이 완전히 둥근 알약형 | 모서리가 살짝 둥근 사각형 |
| 선택 탭 | 테두리를 공유하고 선택 항목에 ✓ | iOS 기본 세그먼트 컨트롤 |
| 선택지 고르기 | 화면 아래에서 올라오는 시트 | 액션시트 |
| 날짜·시간 | Material 다이얼로그 | 인라인 캘린더 / 휠 |
| 목록 | 전체폭 구분선 | 둥근 카드 + 들여쓴 구분선 + 화살표 |
| 최소 터치 영역 | 48dp | 44pt |

날짜·시간 입력은 직접 만든 달력에서 **OS 기본 피커**로 바꿨습니다. 손에 익은 조작감이고, 큰 글씨·다국어·접근성 설정도 OS가 알아서 챙깁니다.
