# 🔧 사용자 직접 수행 가이드 (코드 외 수동 절차)

> 코드는 전부 준비되어 있습니다. 아래는 **계정·키·콘솔 설정** 등 본인만 할 수 있는 절차입니다.
> 순서대로 진행하면 됩니다. ⏱ 표시는 대략 소요 시간.

---

## 1. Firebase 프로젝트 연결 (⏱ 15분) — 필수, 가장 먼저

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `tennis-match`)
2. 프로젝트 설정(⚙️) → 일반 → **앱 추가 → 웹(</>)** 선택 → 앱 등록
3. 표시되는 `firebaseConfig` 값 6개를 **`firebaseConfig.js`** 에 복사
   (apiKey / authDomain / projectId / storageBucket / messagingSenderId / appId)
4. 좌측 **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3`, 프로덕션 모드)
5. 좌측 **빌드 → Authentication → 시작하기 → 전화** 사용 설정
   - 같은 화면 하단 **테스트용 전화번호**에 본인 번호 + 고정 코드(예: `+821012345678` / `123456`)를
     등록해 두면 SMS 없이 개발 테스트 가능
6. 터미널:
   ```bash
   npm i -g firebase-tools
   firebase login
   cd tennis-match
   cp .firebaserc.example .firebaserc   # 열어서 YOUR_FIREBASE_PROJECT_ID 를 실제 ID로 교체
   firebase deploy --only firestore:rules
   ```

## 2. 로컬 실행 (⏱ 10분)

```bash
cd tennis-match
npm install
npm run test:engine      # 대진 엔진 검증 (Firebase 불필요)
npm run test:tournament  # 대회 엔진 검증
npm run test:schedule    # 운영 시간·타임 계산 검증
npm run test:rules       # 보안 규칙 검증 (Java 17+ 필요, 에뮬레이터 자동 실행)
npx expo start          # QR → Expo Go
```
- ⚠️ **푸시 알림은 Expo Go 에서 동작하지 않습니다**(안드로이드 SDK 53+). 앱 흐름 확인만 Expo Go로 하고,
  푸시까지 보려면 4번의 dev build 를 쓰세요.

## 3. Cloud Functions 배포 (⏱ 20분) — 푸시·날씨의 서버측

1. Firebase 콘솔 → 좌측 하단 **요금제 업그레이드 → Blaze(종량제)**
   - 카드 등록만 필요. 이 규모(클럽 수십 명)는 **무료 쿼터 내**라 실제 청구 0원 예상.
2. 기상청 키 발급: https://www.data.go.kr 가입 →
   **"기상청_단기예보 ((구)_동네예보) 조회서비스"** 검색 → 활용신청(즉시 승인) →
   마이페이지에서 **일반 인증키(Decoding)** 복사
3. 터미널:
   ```bash
   cd tennis-match
   firebase functions:secrets:set KMA_SERVICE_KEY   # 위 키 붙여넣기
   cd functions && npm install && cd ..
   firebase deploy --only functions
   ```

## 4. EAS 빌드 (⏱ 30분 + 빌드 대기)

```bash
npm i -g eas-cli
eas login                # Expo 계정 (expo.dev 가입)
cd tennis-match
eas init                 # projectId 가 app.json 에 자동 기록됨 → 푸시 토큰 발급에 사용
eas build --profile development --platform android   # 푸시 포함 개발용 APK
eas build --profile preview --platform android       # 클럽 배포용 APK
```
- iOS 는 Apple Developer($99/년) 가입 후 `--platform ios`. TestFlight 업로드는 `eas submit`.

## 남은 개발 결정 1건 — R-1 (전화 인증 스택)

현재 코드는 **Firebase JS SDK + expo-firebase-recaptcha** 로 배선되어 있습니다(1차 출시 가능).
이 패키지는 deprecated 라 장기적으로는 **`@react-native-firebase/auth` + dev build** 전환이 안전합니다.
전환 시점: 1차 출시 후. 전환 범위: `auth.js`의 sendOtp/confirmOtp + `login.jsx`의 모달 제거 (데이터 계층은 무관).
지금 당장은 아무것도 안 해도 됩니다 — 1번의 테스트용 전화번호로 개발하세요.

# 📱 앱 사용법 — 새로 추가된 기능 (처음 쓰는 분용)

> 아래는 앱을 설치한 뒤 화면에서 하는 일입니다. 개발 지식은 필요 없습니다.
> 모두 **하단 [더보기] 탭** 안에 있습니다.

## A. 처음 한 번만 하는 준비 (총무)

### A-0. 클럽 운영 설정 — **가장 먼저 하세요** ⭐
클럽마다 확보한 코트 면수와 운동 시간이 다르므로, 이것부터 맞춰야 대진표가 제대로 나옵니다.

**클럽을 처음 만들 때**: 클럽 생성 화면에서 바로 입력합니다
(코트 면수 / 시작 시각 / 종료 시각 / 한 타임 길이 → **총 타임 수가 자동 계산**되어 표시됩니다)

**나중에 바꾸려면**: [더보기] → [⚙️ 클럽 설정]
1. **코트 면수**: ＋ / − 버튼으로 조절 (한 면당 4명이 동시에 경기)
2. **운영 시간**: 시작·종료를 `10:00`, `13:00` 형식으로 입력
3. **한 타임 길이**: 20/30/40/45/60분 중 선택
4. 아래에 **자동 계산된 타임표**가 나옵니다
   - 예: 10:00~13:00 · 40분 → `1타임 10:00~10:40`, `2타임 10:40~11:20` … **총 4타임**
5. **잡복 기본 허용** 체크박스 (기본은 해제 = 잡복 금지, 권장)
6. **회비 / 게스트비 / 송금 링크**도 여기서 설정
7. [설정 저장]

> 여기서 정한 값이 **새 모임 등록의 기본값**이 됩니다. 모임마다 코트나 시간이 다르면
> 일정 탭의 모임 등록 화면에서 그 모임만 따로 수정하면 됩니다.
> ([클럽 기본값] 칩을 누르면 설정값으로 되돌아갑니다)

### A-0-2. 코트장이 여러 곳이면 등록 (선택)
한 클럽이 여러 코트장을 쓰는 경우 [더보기] → [🏟 코트장 관리]
1. **[+ 코트장 추가]**
2. **이름 / 면수 / 시작·종료 시각 / 타임 길이** 입력
3. **리드 담당자**: 그 코트장 운영을 맡는 회원을 선택 (미지정 가능)
4. 주소는 선택 사항
5. [추가] — 등록하면 요약이 보입니다: `10:00~13:00 · 3면 · 40분/타임 → 4타임`

> 모임을 등록할 때 **[코트장 선택]** 칩이 뜨고, 고르면 그 코트장의 면수·시간·타임 수가 자동으로 채워집니다.
> 코트장이 한 곳뿐이면 등록하지 않아도 됩니다(클럽 설정의 기본값 사용).

### A-0-3. 대진 기본 방식 정하기
[더보기] → [🎯 대진 설정] — 여기서 정한 값이 **모든 모임의 기본**이 됩니다.
1. **기본 타임 유형** 4가지 중 선택
   - **혼복** (기본): 남녀 2:2
   - **남복/여복**: 동성 복식만
   - **단식**: 1:1 (코트당 2명)
   - **자동**: 홀수 타임 동성복식 / 짝수 타임 혼복 (예전 방식)
2. **NTRP 실력 매칭** 체크 — 켜면 비슷한 실력끼리 같은 코트에 배정하고, 양 팀 실력 합이 비슷해지도록 팀을 나눕니다
   (NTRP 미설정 회원은 조(A/B/C)로 대신 계산)
3. **잡복 기본 허용** 체크 (기본 해제 권장)
4. **편성 기준 우선순위**: ▲▼ 로 순서 변경 (대진 탭의 드래그와 같은 설정)
5. [기본 설정 저장]

### A-1. 회원들 구력(테니스 시작일) 입력
1. [더보기] → [👥 회원]
2. 회원 이름을 누르면 편집창이 열립니다
3. **테니스 시작일**에 `2019-03` 처럼 입력 → [저장]
   - 정확한 날짜를 모르면 연-월만 입력해도 됩니다 (`2019-03` → 3월 1일로 저장)
   - 대회 나갈 때 "구력 3년 이하부" 같은 참가 자격을 확인하는 기준이 됩니다
   - 회원 본인도 자기 것은 직접 수정할 수 있습니다

### A-2. 커플·고정 페어 등록 (해당되는 경우만)
1. [더보기] → [💑 커플·고정 페어]
2. 위에서 **커플** 또는 **고정 페어** 선택
   - **커플**: 부부·커플처럼 같이 오고 같이 가야 하는 사이
     → 두 사람이 항상 같은 타임에 함께 뛰거나 함께 쉽니다. 한 명만 일찍 나와서 기다리는 일이 없어집니다.
     (같은 편일 필요는 없습니다. 서로 상대편이 될 수도 있습니다)
   - **고정 페어**: 대회 준비로 항상 같은 편이어야 하는 조합
     → 항상 한 팀으로 묶여서 대진이 나옵니다
3. 아래 회원 목록에서 **두 명을 탭** → [등록] 버튼
4. 잘못 등록했으면 목록에서 [삭제]

> ⚠️ 한 사람은 하나의 커플/페어에만 등록할 수 있습니다(대진 편성이 불가능해지는 것을 막기 위해서입니다).
> 등록해두면 이후 **대진 생성할 때 자동으로 반영**됩니다. 대진 탭 상단에 "적용 제약: 커플 2쌍…"이라고 표시됩니다.

## B. NTRP 등급 관리

[더보기] → [📊 NTRP 등급]. 탭이 3개입니다.

### B-1. 기준 안내 (먼저 읽어보세요)
- 2.0~5.0까지 7단계가 있고, 각 단계를 누르면 **체크리스트**가 펼쳐집니다
- 예: 3.0은 "포핸드 랠리가 안정적 / 백핸드는 되지만 일관성 부족 / 첫 서브 성공률 50% 내외"
- **대부분 해당되는 가장 낮은 등급**을 고르는 것이 관행입니다 (보수적으로 잡기)

### B-2. 내 등급 (회원 각자)
- **셀프 평가**: 숫자를 눌러 본인 등급 선택. 언제든 수정 가능
- 아래에 나에 대한 **회원 투표 결과**(중앙값)가 보입니다. 누가 몇 점 줬는지는 안 보입니다

### B-3. 클럽 등급표 (투표 / 인증)
- 회원을 누르면 **그 사람 등급에 투표**할 수 있습니다 (본인 제외)
- **총무·운영진**은 같은 화면에서 **인증 등급을 확정**할 수 있습니다
- 최종 표시 등급 우선순위: **운영진 인증 > 회원 투표(중앙값) > 셀프 평가**
  - 즉 운영진이 인증하면 그 값이 최종값이 되고, 인증 전에는 회원들 투표 중앙값이 쓰입니다

## C. 출석 관리

[더보기] → [✅ 출석]. 탭이 2개입니다.

### C-1. 출석 체크 (모임 끝난 뒤, 총무)
1. 위쪽에서 날짜 선택 (최근 5개 모임)
2. 회원별로 [출석] / [결석] 버튼을 누릅니다
3. 편하게 하려면 **[참석자 일괄 출석]** 버튼 → "참석" 의사를 밝힌 사람 전원이 출석 처리됨
   → 그다음 안 온 사람만 [결석]으로 바꾸면 됩니다

### C-2. 출석률 통계 (전원 조회 가능)
- 회원별 출석률(%)이 막대와 함께 표시됩니다 (70% 이상 초록, 40% 미만 빨강)
- **노쇼**: "참석한다"고 해놓고 안 온 횟수 — 회비·페널티 논의할 때 근거가 됩니다

## D. 대회 운영 (핵심)

[더보기] → [🏆 대회]

### D-1. 대회 개설 (총무)
1. **[+ 새 대회 개설]**
2. **대회 정보**: 대회명, 날짜 입력
3. **진행 방식**:
   - ☑️ **예선 조별리그 진행** — 체크하면 조별리그 후 토너먼트
     - **조 개수**(예: 4) / **조별 진출 팀**(예: 2 → 각 조 1·2위가 본선 진출)
   - ☐ 체크를 **해제**하면 **곧바로 토너먼트만** 진행합니다
4. **참가자 선택**: 참가할 회원 이름을 모두 탭 (최소 4명)
5. **팀 구성 방식**:
   - **NTRP 균등**: 잘하는 사람 + 덜 잘하는 사람을 묶어 팀 실력을 비슷하게 (추천)
   - **무작위**: 랜덤 배정
6. **시드 배정**(선택): 구성된 팀 목록에서 강팀 옆에 `1`, `2`… 입력
   - 시드를 주면 강팀끼리 **초반에 만나지 않도록** 자동으로 분산 배치됩니다
   - 예선을 하면 시드 팀들이 서로 다른 조로 갈라지고, 토너먼트에서는 1번 시드와 2번 시드가 결승에서야 만나게 배치됩니다
   - 비워두면 무작위입니다
7. **[대회 개설]**

### D-2. 예선 진행
- 조별로 순위표와 경기 목록이 나옵니다
- 경기 옆 **[입력]** → 점수 두 칸 입력 → [저장]
- 순위는 **승수 → 득실차 → 다득점** 순으로 자동 정렬됩니다
- 진출권(예: 상위 2팀)은 순위 번호가 **연두색**으로 표시됩니다
- 예선 경기를 **모두 입력**하면 아래 버튼이 활성화됩니다 → **[예선 종료 → 본선 대진 생성]**

### D-3. 본선 토너먼트
- 8강 → 준결승 → 결승 순으로 대진표가 자동 생성됩니다
- 참가 팀이 8팀, 16팀처럼 딱 떨어지지 않으면 **상위 시드에게 부전승**이 자동 배정됩니다 ("부전승" 표시)
- 경기마다 [입력] → 점수 저장 → **승자가 다음 라운드로 자동 진출**
- 결승까지 입력하면 상단에 **🏆 우승 팀**이 표시되고 대회가 "종료" 상태가 됩니다

### D-4. 기록 보관
- 대회 목록에서 **진행 중 / 지난 대회 기록**이 나뉘어 보입니다
- 지난 대회를 누르면 그때의 조별 순위·토너먼트 결과를 그대로 다시 볼 수 있습니다

## D-5. 대회를 실력 그룹으로 나눠 진행하기
대회 개설 화면에서 **[수준별 그룹으로 진행]** 을 체크하면 토너먼트 대신 실력 그룹제로 운영합니다.
1. **그룹별 정원**을 쉼표로 입력 — 예: `8,8,6` (앞쪽이 상위 그룹)
2. **[자동 배정]** → 참가자를 **남·여 각각 NTRP 순서로** 그룹에 배분합니다
   - 각 그룹의 성비가 전체 성비와 비슷하게 유지됩니다
   - 그룹마다 `NTRP 3.5~4.5` 처럼 실력 범위가 표시됩니다
3. **수동 조정**: 회원 이름을 누르면 다음 그룹으로 이동합니다 (누를 때마다 A→B→C→A 순환)
4. [대회 개설] — 이후 대회 상세 화면에서 그룹별 명단을 보고 그룹 안에서 자유롭게 시합을 진행합니다
   (운영진은 여기서도 이름을 눌러 그룹을 바꿀 수 있습니다)

> 정원 합이 실제 참가 인원과 달라도 됩니다. 모자라면 마지막 그룹이 늘어나고, 남으면 자동으로 줄어듭니다.

## E. 타임별로 경기 유형 바꾸기

대진 탭에서 **[타임별 경기 유형]** 카드를 보면 타임마다 칩이 4개씩 있습니다.
- 기본값은 [🎯 대진 설정]에서 정한 유형이고, **여기서 특정 타임만 다르게** 바꿀 수 있습니다
- 예: `1타임 혼복 · 2타임 남복/여복 · 3타임 단식 · 4타임 혼복`
- 오른쪽 위 **[✓ 실력매칭]** 칩으로 이 모임만 실력 매칭을 켜고 끌 수 있습니다
- 바꾼 뒤 **[대진 재생성]** 을 눌러야 반영됩니다

> **단식 타임**은 코트당 2명이 들어갑니다(남단식/여단식 자동 구분). 4면이면 8명이 동시에 경기하므로,
> 인원이 많을 때 대기 인원이 늘어납니다. 반대로 인원이 적을 때 유용합니다.

## F. 인원이 안 맞을 때 — 잡복 경고창

대진 생성 버튼을 누르면 **참석 인원의 성비를 자동으로 검사**합니다.
기본 원칙은 **잡복 금지**(남복=남4 / 여복=여4 / 혼복=남2여2 만 허용)입니다.

### E-1. 생성 전에 미리 보기
대진 탭 상단에 현재 상태가 항상 표시됩니다:
- `✓ 3면 모두 잡복 없이 편성 가능` — 그냥 생성하면 됩니다
- `△ 잡복 없이 1면만 가능 (3면 사용하려면 여성 4명 추가)` — 아래 경고창이 뜹니다
- `⚠ 인원 부족 — 1면 진행에 여성 1명 더 필요` — 생성이 불가능합니다

### E-2. 경고창 3종류

**① 일부 코트만 사용 가능할 때**
```
일부 코트만 사용됩니다
현재 참석 8명 (남 5 · 여 3) · 확보 코트 2면
 ▸ 잡복 없이: 1면만 사용 (나머지는 대기)
 ▸ 2면 모두 쓰려면: 여성 1명 추가 필요
 ▸ 잡복을 허용하면: 2면까지 사용 가능
잡복(남3여1 등)을 허용하시겠습니까?
     [아니오 (잡복 없이)]   [예, 잡복 허용]
```
- **아니오** → 1면만 쓰고 나머지 인원은 그 타임에 쉽니다
- **예** → 2면을 모두 쓰고, 남는 성비는 잡복으로 편성합니다

**② 잡복 없이는 아예 안 될 때** (예: 남 3명 · 여 1명)
```
잡복 없이는 편성할 수 없습니다
 ▸ 잡복 없이 하려면: 남성 1명 추가 필요   ← 남자 1명 더 오면 남복 가능
 ▸ 잡복을 허용하면: 지금 인원으로 1면 진행 가능
잡복(남3여1 등)을 허용하시겠습니까?
            [아니오]   [예, 잡복으로 편성]
```

**③ 잡복을 허용해도 불가능할 때** (4명 미만이거나 성비가 극단적일 때)
```
대진표를 만들 수 없습니다
현재 참석 3명 (남 2 · 여 1)
복식 한 경기에는 4명이 필요합니다.
 ▸ 최소 1면이라도 진행하려면
   여성 1명이 더 필요합니다.
                                    [확인]
```
→ 이 경우엔 **몇 명이 더 필요한지 정확히 알려주므로**, 게스트를 부르거나 참석자를 더 모으면 됩니다.

### E-3. 잡복으로 만든 대진표
- 해당 경기에 **`잡복`** 이라는 표시가 붙습니다
- 잡복은 **최후 수단**이라 정규 조합(남복·여복·혼복)으로 채울 수 있는 코트는 그대로 정규로 편성되고,
  남는 인원만 잡복으로 묶입니다
- 팀은 성비가 최대한 균형이 되도록 나눕니다 (남3여1이면 `남2 vs 남1여1`)
- 매번 묻는 게 번거로우면 [더보기] → [⚙️ 클럽 설정] → **잡복 기본 허용**을 체크하세요

## G. 자주 묻는 상황

| 상황 | 해결 |
|---|---|
| 커플인데 대진에서 갈라져 나옴 | 커플은 "같은 시간대"를 맞추는 것이지 같은 편이 되는 게 아닙니다. 같은 편으로 묶으려면 **고정 페어**로 등록하세요 |
| 고정 페어인데 대진에 안 묶임 | 두 사람이 **모두 참석(RSVP 참석)** 상태여야 적용됩니다. 대진 탭 상단의 "적용 제약" 표시를 확인하세요 |
| 대진 생성이 안 됨 | 경고창이 **몇 명이 더 필요한지** 알려줍니다. 잡복을 허용하면 되는 경우도 경고창에서 바로 선택할 수 있습니다 |
| 코트가 남는데 대진이 1면만 나옴 | 성비상 정규 조합이 안 나오는 경우입니다. 경고창에서 [예, 잡복 허용]을 누르면 남는 코트도 사용합니다 |
| 모임마다 코트·시간이 다름 | [더보기 → 클럽 설정]은 **기본값**입니다. 일정 탭의 모임 등록에서 그 모임만 코트/타임을 바꿔 입력하세요 |
| 타임 수를 직접 정하고 싶음 | 모임 등록 화면의 "타임" 칸에 직접 입력하면 됩니다 (클럽 설정의 자동 계산값을 덮어씀) |
| 대회 참가자가 홀수 | 팀이 자동으로 짝지어지고 남는 1명은 팀에 포함되지 않습니다. 참가자를 짝수로 맞춰주세요 |
| NTRP 투표를 바꾸고 싶음 | 같은 회원을 다시 눌러 다른 점수를 선택하면 덮어써집니다 |
| 코트장마다 시간이 다름 | [더보기 → 코트장 관리]에 각각 등록하면 모임 등록 때 골라서 쓸 수 있습니다 |
| 특정 타임만 단식으로 하고 싶음 | 대진 탭 → [타임별 경기 유형]에서 그 타임만 [단식] 선택 후 재생성 |
| 실력 차이가 너무 남 | [대진 설정] 또는 대진 탭의 [실력매칭] 칩을 켜세요. NTRP가 없는 회원은 조(A/B/C)로 계산됩니다 |
| 대회를 실력별로 나누고 싶음 | 대회 개설 시 [수준별 그룹으로 진행] 체크 → 그룹 정원 입력 → [자동 배정] |
