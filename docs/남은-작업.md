## FIX-12 분해 결과 (완료 기록)
`server/db.ts`(2,292줄)를 **원본 라인 그대로 슬라이스**(커버리지 2,277/2,277)해 분해:

| 모듈 | 내용 | 줄수 |
|---|---|---|
| `dbmodules/core.ts` | 커넥션·마이그레이션·SQL 빌더·상수·자동분류 bake | ~500 |
| `dbmodules/transactions.ts` | 거래 CRUD·제외·업로드·자동제외 배치 | ~500 |
| `dbmodules/rules.ts` | 매핑 규칙 CRUD·bake·시드·자동생성 | ~420 |
| `dbmodules/stats.ts` | 월별·카테고리·피벗·KPI·L3·저축·수입분포 | ~380 |
| `dbmodules/users.ts` | 사용자·설정 | ~150 |
| `dbmodules/groups.ts` | 가족 공유 그룹 | ~135 |
| `dbmodules/budgets.ts` | 예산 목표·임계치 | ~100 |
| `dbmodules/subscriptions.ts` | 구독 감지 | ~65 |
| `dbmodules/accounts.ts` | 계좌 표시/숨김 | ~45 |
| `server/db.ts` | **배럴(재-export)** — 기존 `from "./db"` 전부 호환 | 13 |

- 순환 참조 2건(core 마이그레이션 → rules.bake / transactions.runAutoExclusions)은 **런타임 동적
  임포트**로 해소(정적 그래프는 비순환).
- 의도적 변경은 단 3가지: core 헬퍼 9개 `export` 승격, 동적 임포트 2건. 나머지는 순수 이동.
- 검증: tsc 심볼 누락 0·배럴 모호성 0, 배럴 로드 84 export(필수 47심볼 전부), 서버 부팅,
  vitest 43 통과, vite 빌드 통과.
