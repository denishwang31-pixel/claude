## ⏳ FIX-12 나머지 · server/db.ts 모놀리스 분해 (P2, 유일한 잔여)
**왜 이번에 안 했나**: 이 저장소는 `tsconfig.server.json` 이 **NodeNext** 라 상대 임포트가 `.js`
확장자를 요구하는데, 기존 코드 전체가 확장자 없이 임포트(이미 tsc 경고 상태, tsx 로만 구동)한다.
2,300줄 db.ts 를 디렉터리로 쪼개면 `./db` 임포트 해석이 바뀌어 **모듈 해석이 깨질 위험**이 크고,
기능 이득은 0(순수 정리)이다. 라이브 DB 없이 전량 회귀검증도 불가하므로 **독립 PR** 로 분리 권장.

**안전한 분해 방법(권장)** — `db.ts` 파일명은 유지하고 내부만 분리:
1. 새 디렉터리 `server/dbmodules/` 생성(이름을 `db/` 로 하지 말 것 — `./db` 파일과 충돌).
2. `dbmodules/core.ts` 에 공용 엔진 이동: `getDb`, `runAutoMigrations`, SQL 식 빌더
   (`bankSaladMapSQL`/`keywordMapSQL`/`autoMapSQL`/`buildEffectiveCategoryExpr`/`ownerSQL`/
   `dateRangeSQL`/`buildFiltersSQL`), 상수(`APP_L3_CATEGORIES`/`SAVINGS_CATS`/`TRANSFER_CATS`/`OWNERS`),
   remap 헬퍼, `categoryToRuleType`.
3. 기능별 모듈: `transactions.ts`, `rules.ts`(bake 포함), `stats.ts`, `budgets.ts`,
   `subscriptions.ts`, `accounts.ts`, `groups.ts`, `users.ts` — 모두 `./core` 에서 공용 임포트.
4. **`server/db.ts` 는 배럴로 축소**: `export * from "./dbmodules/core"; export * from "./dbmodules/transactions"; …`
   → 외부(`from "./db"`)는 무변경.
5. 검증: `npx tsc -p tsconfig.server.json`(참조 누락 즉시 검출) + 서버 부팅 + `npm test` +
   Neon 연결 후 대시보드 수치 대조. **로직 수정 없이 이동만**, 커밋 하나로.
6. 클라이언트: `Home.tsx` 는 이미 헤더 추출 완료. 추가로 원하면 탭 렌더 스위치를 `TabRouter` 로 분리.
